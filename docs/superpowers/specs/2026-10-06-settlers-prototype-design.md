# Прототип Settlers-подобной игры — дизайн

> **Исторический документ.** Описывает самый первый прототип (5 зданий, 3 ресурса). С тех пор почти всё из «Вне объёма» сделано; текущее состояние — в [README](../../../README.md), устройство кода — в [CLAUDE.md](../../../CLAUDE.md), план — в [ROADMAP](../../ROADMAP.md).

## Цель
Браузерный прототип в изометрическом 2D со спрайтами, показывающий «оживающую» мини-экономику:
лесоруб → лесопилка → доски → новые постройки.

## Стек
TypeScript + Vite + PixiJS 8 (WebGL), Vitest для тестов. Все спрайты генерируются кодом на canvas
при старте и пакуются в один атлас.

## Архитектура
- `src/sim/` — чистая симуляция без зависимостей от рендера. Фиксированный тик 10/с, детерминированный
  RNG по сиду. Карта, A*, поселенцы с очередью задач, здания, логистика.
- `src/render/` — PixiJS: атлас текстур, изометрическая проекция (тайл 64×32), сортировка по глубине,
  камера; интерполяция позиций поселенцев между тиками. Только читает состояние sim.
- `src/ui/` — HTML-оверлей: ресурсы, скорость, меню постройки, инфо о здании.

## Мир
Карта 64×64 по сиду: вода, песок, трава, скалы, леса. Около центра — замок и гарантированная роща.
Деревья блокируют проход, медленно разрастаются и растут (4 стадии). Дорог нет, A* по сетке, 8 направлений.

## Экономика
- Замок (3×3): склад, источник поселенцев. Старт: 12 носильщиков, 3 строителя, 14 досок.
- Лесоруб (2×2, 2 доски): рубит ближайшее зрелое дерево в радиусе 8, кладёт бревно у входа (≤4).
- Лесопилка (2×2, 3 доски): бревно → доска (вход ≤4, выход ≤4).
- Стройка: носильщики подносят доски, строитель тратит 30 тиков работы на единицу материала.
  Готовому зданию нужен работник — им становится свободный носильщик.
- Логистика: запросы (стройки, вход лесопилки) сопоставляются с ближайшим предложением (выходы зданий,
  склад замка) и ближайшим свободным носильщиком; излишки уносятся в замок. Резервирования снимаются
  при отмене задания.
- Замок порождает нового носильщика раз в 20 с (лимит населения 40).

## Управление
Перетаскивание/WASD/стрелки/край экрана — камера, колесо — зум к курсору. Меню постройки → «призрак»
с зелёной/красной подсветкой, ЛКМ — поставить, ПКМ/Esc — отмена. Клик по зданию — инфо. Скорость 1×/2×/4×, пауза.

## Тесты
Vitest для sim: A*, правила размещения, сквозной сценарий экономики без браузера.

## Вне объёма
Лесничий, камень, еда, территория, инструменты, сохранения, звук, Web Worker.
