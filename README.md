# Settlers — браузерный прототип

Прототип экономической стратегии в духе The Settlers 3/4: изометрическое 2D, спрайты, поселенцы, которые сами рубят лес, пилят доски и строят дома. Всё работает в браузере без установки.

![Скриншот](docs/screenshot.jpg)

## Запуск

Нужен Node.js 20.19+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Карта генерируется случайно; чтобы сыграть на той же карте ещё раз, добавьте к адресу `?seed=42` (сид текущей карты пишется в консоль браузера). Размер карты задаётся параметром `?size=128` (по умолчанию 64), число игроков — `?players=1` (по умолчанию 2: вы и пока пассивный соперник в противоположном углу карты).

## Как играть

На старте есть замок со складом, 12 носильщиков, 3 строителя, 20 досок, 10 камней и запас инструментов. Рядом с замком всегда есть роща, каменоломня, пруд и небольшая гора с углём и железом.

Здания сгруппированы во вкладки меню строительства:

| Вкладка | Здание | Стоимость | Что делает |
|---|---|---|---|
| Поселение | Малый / средний / большой дом | 2🪚 1🪨 / 3🪚 2🪨 / 5🪚 4🪨 | Постепенно выпускает 4 / 8 / 14 новых носильщиков. Только так растёт население — замок поселенцев не рождает |
| | Склад | 3🪚 2🪨 | Хранилище: излишки везут на ближайший склад, а не через всю карту в замок |
| Сырьё | Дом лесоруба | 2🪚 | Рубит зрелые деревья в радиусе 8 клеток |
| | Дом лесничего | 2🪚 | Сажает деревья в радиусе 6, чтобы лес не кончался |
| | Лесопилка | 2🪚 2🪨 | Бревно → доска |
| | Каменотёс | 2🪚 | Добывает камень из глыб в радиусе 8; камень конечен |
| Еда | Водокачка | 2🪚 | Черпает воду с берега (вода бесконечна) |
| | Рыбак | 2🪚 | Ловит рыбу с берега; запас рыбы в воде восполняется |
| | Ферма | 3🪚 1🪨 | Засевает поля вокруг себя и собирает созревшее зерно |
| | Мельница | 3🪚 2🪨 | Зерно → мука |
| | Пекарня | 2🪚 2🪨 | Мука + вода → хлеб |
| | Свиноферма | 3🪚 1🪨 | Зерно + вода → свинья |
| | Бойня | 2🪚 2🪨 | Свинья → 2 мяса |
| | Виноградник | 2🪚 1🪨 | Виноградарь сажает лозы (многолетние: после сбора снова плодоносят) и собирает виноград |
| | Винодельня | 2🪚 2🪨 | 2 винограда → вино (пригодится для магии) |
| Горное дело | Угольная шахта / железный рудник / золотой рудник / каменоломня в горе | 3🪚 1🪨 | Строится только на горе. Шахтёр съедает одну единицу любой еды (🍞, 🐟 или 🥩) и добывает единицу руды из клеток в радиусе 3. Когда руда кончается, шахта выработана |
| | Геолог | команда | Клик по своей горе: свободный носильщик идёт туда геологом, осматривает до 8 клеток вокруг и ставит таблички с найденной рудой (крестик — пусто) |
| Металл | Плавильня железа | 2🪚 3🪨 | Железная руда + уголь → железо |
| | Плавильня золота | 2🪚 3🪨 | Золотая руда + уголь → золото |
| | Инструментальщик | 3🪚 2🪨 | Железо + уголь → инструмент. Куёт то, чего ждут здания, и держит по 2 штуки каждого в запасе; иначе простаивает |
| Военное | Оружейник | 3🪚 2🪨 | Железо + уголь → меч |
| | Сторожевая башня | 2🪚 3🪨 | Гарнизон до 3 солдат; пока внутри есть хотя бы один, расширяет землю на 8 клеток |

**Инструменты.** Большинству профессий нужен свой инструмент: лесорубу топор, пильщику пила, каменотёсу и шахтёру кирка, лесничему лопата, фермеру коса, рыбаку удочка, строителю молоток. Носильщик сначала забирает инструмент со склада и только потом становится работником; нет инструмента — здание ждёт (это видно в информации о здании). На старте в замке есть запас инструментов, дальше их делает инструментальщик. Когда строек больше, чем строителей, носильщики с молотками становятся новыми строителями.

Экономика работает сама: носильщики подносят материалы на стройки и сырьё в мастерские, излишки уносят в замок. Дефицитное сырьё делится между потребителями поровну — например, зерно между мельницей и свинофермой. Готовое здание занимает свободный носильщик и становится его работником, поэтому для новых зданий нужны дома.

**Солдаты и бой.** Солдаты живут в гарнизонах: в замке до 12, в башне до 3; на старте в замке 3 солдата. Пустые места в башнях заполняются солдатами из резерва замка, а если резерва нет — носильщик берёт меч со склада и записывается в солдаты (так же замок набирает себе резерв, пока есть мечи). Каждое военное здание всегда оставляет у себя хотя бы одного солдата.

Чтобы атаковать, кликните по вражеской башне или замку: в информации видно число защитников и сколько ваших свободных солдат из военных зданий в радиусе 30 клеток можно послать; кнопками «−»/«+» выберите число и нажмите «⚔ Атаковать». У двери цели атакующие по одному бьются с защитниками; когда защитников не осталось, ваш солдат занимает здание — оно и его земля переходят к вам, а чужие мирные здания, оказавшиеся на вашей земле, сгорают. Спорная земля между военными зданиями достаётся ближайшему.

Строить можно только на своей земле: она подсвечена, а за синей границей земля затемнена. Добытчики, лесничие и фермеры тоже работают только в своих границах, так что за новыми лесами, каменоломнями и водой придётся расширяться башнями. Поля проходимы, но строить на них нельзя.

Земля не плоская: трава слегка холмистая, горы поднимаются над равнинами, а вода лежит ниже всего. С гор к морю текут реки (на больших картах горы тянутся хребтами), а на реках через каждые несколько клеток есть броды — мелководье, по которому можно перейти. Границы между водой, песком, травой и горами плавные.

Обычные здания ставятся на ровное или пологое место. Если участок заметно наклонный, но не слишком крутой, стройка сначала ждёт **землекопа**: носильщик берёт лопату и выравнивает площадку, и только после этого приходят строители (в информации о стройке видно «Выравнивание»). Слишком крутой склон «призрак» здания показывает красным. Луг вокруг замка всегда ровный. Шахтам наклон не мешает.

По горам можно ходить, но строить на них можно только шахты. Непроходимы лишь скальные вершины, усыпанные валунами.

Деревья растут в четыре стадии (рубить можно только взрослые), поля — тоже в четыре (убирать можно только спелые). Ни саженцы, ни самосев никогда не перекрывают проходы.

### Управление

| Действие | Клавиши / мышь |
|---|---|
| Двигать камеру | перетаскивание мышью, WASD, стрелки, край экрана |
| Зум | колесо мыши |
| Выбрать здание для постройки | кнопки внизу; `Tab` — следующая вкладка, `1`–`9` — здание на открытой вкладке |
| Поставить | ЛКМ (с Shift — несколько подряд) |
| Отменить постройку | ПКМ или Esc |
| Информация о здании | клик по зданию; там же кнопки «⬆ Приоритет» (стройка или мастерская обслуживается первой) и «🔨 Снести» (по второму клику) |
| Пауза / скорость | пробел, кнопки 1× / 2× / 4× |
| Весь склад / статистика | кнопки 📦 / 📊 в верхней панели |
| Мини-карта | правый нижний угол; клик переносит камеру |
| Сохранить / загрузить | кнопки 💾 / 📂 справа вверху (одна ячейка сохранения в браузере) |

## Технологии

- **TypeScript + Vite** — сборка и dev-сервер.
- **PixiJS 8** — рендер на WebGL.
- **Vitest** — тесты симуляции.

Все спрайты (земля, деревья, здания, поселенцы) рисуются кодом на Canvas 2D при старте и собираются в один текстурный атлас, поэтому внешних картинок нет.

## Структура

```
src/sim/      симуляция без зависимостей от браузера: карта, A*, поселенцы, здания, логистика
src/render/   изометрический рендер на PixiJS, генерация спрайтов, камера
src/ui/       HTML-интерфейс, ввод, общее состояние
tests/        тесты симуляции
docs/         спецификация прототипа
```

Симуляция идёт фиксированными тиками (10 в секунду) и детерминирована по сиду, рендер только читает её состояние и сглаживает движение между тиками. Подробнее об устройстве кода — в [CLAUDE.md](CLAUDE.md) и [спецификации](docs/superpowers/specs/2026-10-06-settlers-prototype-design.md).

## Команды

```bash
npm run dev         # dev-сервер
npm test            # тесты
npm run typecheck   # проверка типов
npm run build       # production-сборка в dist/
npm run sim:probe   # проверка экономики: час игры на нескольких картах
npm run sim:bench   # замер скорости симуляции: карта 256×256, 1000 поселенцев
```
