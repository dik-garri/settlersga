# Settlers — браузерный прототип

Прототип экономической стратегии в духе The Settlers 3/4: изометрическое 2D, спрайты, поселенцы, которые сами рубят лес, пилят доски и строят дома. Всё работает в браузере без установки.

![Скриншот](docs/screenshot.jpg)

**Играть в браузере:** https://dik-garri.github.io/settlersga/ (собирается и публикуется автоматически при каждом пуше в `main`).

## Запуск

Нужен Node.js 20.19+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Карта генерируется случайно; чтобы сыграть на той же карте ещё раз, добавьте к адресу `?seed=42` (сид текущей карты пишется в консоль браузера). Размер карты задаётся параметром `?size=128` (по умолчанию 64; играбельны карты до `?size=512`), число игроков — `?players=1` (по умолчанию 2: вы и компьютерный соперник в противоположном углу карты; `?players=4` — вы и три компьютерных соперника, удобнее на больших картах). С `?ai=off` соперники пассивны, с `?fog=off` выключается туман войны (для отладки). С `?art=3d` часть графики заменяется пробной графикой в стиле Settlers 4 из Blender: трава, дом лесоруба (с этапами стройки: колышки, каркас, стены, крыша), деревья, камни, кучи брёвен, досок и камня у дверей (сколько лежит, столько и видно), носильщик-римлянин.

## Как играть

На старте есть замок со складом, 12 носильщиков, 3 строителя, 20 досок, 10 камней и запас инструментов. Рядом с замком всегда есть роща, каменоломня, пруд и небольшая гора с углём и железом.

Здания сгруппированы во вкладки меню строительства:

**Инструменты.** Большинству профессий нужен свой инструмент: лесорубу топор, пильщику пила, каменотёсу и шахтёру кирка, лесничему лопата, фермеру коса, рыбаку удочка, строителю молоток. Носильщик сначала забирает инструмент со склада и только потом становится работником; нет инструмента — здание ждёт (это видно в информации о здании). На старте в замке есть запас инструментов, дальше их делает инструментальщик. Когда строек больше, чем строителей, носильщики с молотками становятся новыми строителями.

Экономика работает сама: носильщики подносят материалы на стройки и сырьё в мастерские, излишки уносят в замок. Дефицитное сырьё делится между потребителями поровну — например, зерно между мельницей и свинофермой. Готовое здание занимает свободный носильщик и становится его работником, поэтому для новых зданий нужны дома.

**Солдаты и бой.** Бойцы бывают двух видов: мечник (меч, крепче в ближнем бою) и лучник (лук, стреляет издалека на 5 клеток, но слабее врукопашную). Они живут в гарнизонах: в замке до 12, в башне до 3, в большой башне до 6, в крепости до 12; на старте в замке 6 мечников. Часть мест в каждом здании отведена лучникам. Пустые места заполняются бойцами из резерва замка; новых бойцов готовит только казарма: без неё мечи и луки просто лежат на складе. Сначала каждая пустая башня получает хотя бы одного бойца, потом тыловые здания отдают лишних в передовые, ближе к врагу.

**Оборона.** У каждого военного здания есть неприкосновенный минимум гарнизона: эти бойцы никогда не уходят ни в другие башни, ни в атаку (замок держит 4, крепость 3, большая башня 2, башня 1). Защитники у своей двери бьют сильнее (бонус обороны здания), лучники гарнизона обстреливают подходящих врагов, а раненые внутри здания понемногу лечатся.

**Уровни.** Золото в замке (или подвезённое в большую башню и крепость) обучает бойцов: одна единица золота поднимает самого слабого бойца внутри на уровень, всего уровней три. Каждый уровень даёт +30% к здоровью и силе удара; уровень виден шевронами над головой бойца, а состав гарнизона по видам и уровням — в информации о здании.

Чтобы атаковать, кликните по вражеской башне или замку: в информации видно число защитников, бонус обороны здания и сколько ваших свободных бойцов из военных зданий в радиусе 30 клеток можно послать (и кто пойдёт: мечники и лучники вперемешку); кнопками «−»/«+» выберите число и нажмите «⚔ Атаковать». У двери цели мечники по одному бьются с защитниками, а лучники поддерживают их стрелами; когда защитников не осталось, ваш боец занимает здание — оно и его земля переходят к вам, а чужие мирные здания, оказавшиеся на вашей земле, сгорают. Спорная земля между военными зданиями достаётся ближайшему.

**Компьютерный соперник.** Играет по тем же правилам, что и вы: строит те же здания из тех же материалов, посылает геологов, набирает солдат и лучников, добывает золото для обучения и расширяется самыми крупными башнями, которые может построить и занять, — сначала к ресурсам, потом к вам. Первые 25 минут он не нападает; дальше атакует, когда сила его свободных бойцов (с учётом уровней) заметно больше силы защитников цели с бонусом обороны (примерно 1,2 к 1). Руду он видит только там, где побывали его геологи, а ваши здания — только там, где рассеялся его туман войны: пока он вас не нашёл, он ведёт башни в неразведанные земли, к центру карты; число защитников он знает, лишь пока здание в поле зрения его построек. Для рудника, которому не хватает руды, он посылает геологов и тянет башни к горам.

**Победа и поражение.** Кто потерял замок, выбывает: его поселенцы гибнут, а оставшиеся здания сгорают. Вы победили, когда взяты замки всех соперников, и проиграли, если взят ваш. В конце показывается итог партии с кнопками «Новая игра» и «Смотреть дальше».

Строить можно только на своей земле: она подсвечена, а за синей границей земля затемнена. Добытчики, лесничие и фермеры тоже работают только в своих границах, так что за новыми лесами, каменоломнями и водой придётся расширяться башнями. Поля проходимы, но строить на них нельзя.

Земля не плоская: трава слегка холмистая, горы поднимаются над равнинами, а вода лежит ниже всего. С гор к морю текут реки (на больших картах горы тянутся хребтами), а на реках через каждые несколько клеток есть броды — мелководье, по которому можно перейти. Границы между водой, песком, травой и горами плавные.

Вдали от воды встречаются **пустыни**: по ним можно ходить и на них можно строить, но там ничего не растёт — ни деревья, ни поля. В низинах у воды бывают **болота**: строить и сажать там нельзя, а ходят по ним вдвое медленнее, поэтому поселенцы обходят болото, если сухая дорога ненамного длиннее. Вокруг замка ни пустынь, ни болот нет.

**Туман войны.** Сначала вы видите только окрестности замка, остальная карта чёрная. Земля открывается вокруг ваших зданий (военные видят дальше своей земли) и вокруг поселенцев, которые ходят по ней. Однажды увиденное остаётся на карте, но если там сейчас никого из ваших нет, местность затемнена: чужих поселенцев там не видно, а у вражеских зданий не видно гарнизона. Мини-карта показывает то же самое. Компьютерный соперник пока видит всю карту.

Как в Settlers 4, пока выбрано здание для постройки, на карте точками отмечены все места, где оно помещается: **зелёные** — ровно, **жёлтые** — участок наклонный, сначала его выровняет землекоп. Каждую стройку сначала расчищает **землекоп** с лопатой (на старте их двое; для наклонных участков носильщики берут лопаты и становятся землекопами), носильщики тем временем уже несут материалы, и только потом приходят строители (в информации о стройке видно «Выравнивание»). Слишком крутой склон «призрак» здания показывает красным. Шахтам землекоп не нужен. Флажок у двери поднимается, когда здание заселено: в мастерскую пришёл работник, в башню — солдаты.

По горам можно ходить, но строить на них можно только шахты. Непроходимы лишь скальные вершины, усыпанные валунами.

Деревья растут в четыре стадии (рубить можно только взрослые), поля — тоже в четыре (убирать можно только спелые). Ни саженцы, ни самосев никогда не перекрывают проходы.

### Управление

| Действие | Клавиши / мышь |
|---|---|
| Двигать камеру | перетаскивание мышью, WASD, стрелки, край экрана |
| Зум | колесо мыши |
| Выбрать здание для постройки | кнопки внизу; `Tab` — следующая вкладка, `1`–`9` — здание на открытой вкладке |
| Поставить | ЛКМ (с Shift — несколько подряд) |
| Отменить постройку | ПКМ или Esc |
| Информация о здании | клик по зданию; там же кнопки «⬆ Приоритет» (стройка или мастерская обслуживается первой) и «🔨 Снести» (по второму клику) |
| Пауза / скорость | пробел, кнопки 1× / 2× / 4× |
| Весь склад / статистика | кнопки 📦 / 📊 в верхней панели |
| Мини-карта | правый нижний угол; клик переносит камеру |
| Сохранить / загрузить | кнопки 💾 / 📂 справа вверху (одна ячейка сохранения в браузере) |
| Звук | справа вверху: 🔊 — выключить/включить (или `M`), ползунок — громкость, ♫ — музыка |

### Звук

Звук включается после первого клика или нажатия клавиши (так требуют браузеры). Слышно то, что видно на экране: стук топоров и молотов, кирки, пилу, плеск воды, падение деревьев, звон мечей и тетиву луков, сигнал готовой стройки. Чем дальше от центра экрана, тем тише, а слева и справа звук идёт из соответствующей колонки. Фоном играет спокойная музыка и поют птицы. Громкость, выключение звука и музыки запоминаются в браузере.

## Технологии

- **TypeScript + Vite** — сборка и dev-сервер.
- **PixiJS 8** — рендер на WebGL.
- **Vitest** — тесты симуляции.

Все спрайты (земля, деревья, здания, поселенцы) рисуются кодом на Canvas 2D при старте и собираются в текстурный атлас, а все звуки синтезируются на WebAudio, поэтому внешних картинок и звуковых файлов нет.

## Структура

```
src/sim/      симуляция без зависимостей от браузера: карта, A*, поселенцы, здания, логистика
src/render/   изометрический рендер на PixiJS, генерация спрайтов, анимации и эффекты, камера
src/audio/    синтез звуков, музыка, громкость и позиционирование
src/ui/       HTML-интерфейс, ввод, общее состояние
tests/        тесты симуляции
docs/         спецификация прототипа
```

Симуляция идёт фиксированными тиками (10 в секунду) и детерминирована по сиду, рендер только читает её состояние и сглаживает движение между тиками. Подробнее об устройстве кода — в [CLAUDE.md](CLAUDE.md) и в [исходной спецификации прототипа](docs/superpowers/specs/2026-10-06-settlers-prototype-design.md) (историческая, описывает самую первую версию).

## Команды

```bash
npm run dev         # dev-сервер
npm test            # тесты
npm run typecheck   # проверка типов
npm run build       # production-сборка в dist/
npm run sim:probe   # проверка экономики: час игры на нескольких картах
npm run sim:bench   # замер скорости симуляции: карта 256×256, 1000 поселенцев
npm run sim:ai      # компьютер против компьютера (или против пассивного игрока: --passive=1) на час игры
npm run art:render  # перерендерить 3D-спрайты в public/art/3d (нужен Blender; можно перечислить: -- carrier tree)
npm run art:ground  # пересоздать фактуры земли (трава) в public/art/3d (нужен Blender)
```
