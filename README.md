# Settlers — браузерный прототип

Прототип экономической стратегии в духе The Settlers 3/4: изометрическое 2D, спрайты, поселенцы, которые сами рубят лес, пилят доски и строят дома. Всё работает в браузере без установки.

![Скриншот](docs/screenshot.jpg)

**Играть в браузере:** https://dik-garri.github.io/settlersga/ (собирается и публикуется автоматически при каждом пуше в `main`).

## Запуск

Нужен Node.js 20.19+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Карта генерируется случайно; чтобы сыграть на той же карте ещё раз, добавьте к адресу `?seed=42` (сид текущей карты пишется в консоль браузера). Размер карты задаётся параметром `?size=128` (по умолчанию 64; играбельны карты до `?size=1024`), число игроков — `?players=1` (по умолчанию 2: вы и компьютерный соперник в противоположном углу карты; `?players=4` — вы и три компьютерных соперника, удобнее на больших картах). С `?teams=1,1,2,2` игроки делятся на команды: союзники не нападают друг на друга, побеждают вместе и видят всё, что видит союзник (общий туман войны). С `?ai=off` соперники пассивны, с `?fog=off` выключается туман войны (для отладки). Для разработки есть демо-карта **`?demo`** (например, https://dik-garri.github.io/settlersga/?demo): она сама обстраивается за пару секунд и показывает всё сразу — все здания готовыми и с работниками, стройки, замороженные на каждом этапе, кучи всех товаров, геолога за разведкой, первопроходца у границы и вора у склада второго игрока, все украшения; без тумана (`?fog=on` — с туманом). Вся графика по умолчанию — в стиле Settlers 4, из Blender (`?art=classic` — старая, нарисованная кодом): земля всех видов (пляжи, вода, горы, пустыня, болото), ели и лиственные деревья, кусты травы, цветы и грибы на лугах, поля и тропы, все здания (с этапами стройки: колышки, каркас или фундамент, стены, крыша), камни, кучи всех товаров у дверей (сколько лежит, столько и видно; больше восьми — следующая куча рядом), все поселенцы и солдаты (3D-фигуры в тунике цвета игрока, с инструментом своей профессии; у мечника шлем и щит, у лучника лук и колчан).

## Как играть

На старте есть замок со складом, 12 носильщиков, 3 строителя, 2 землекопа, 20 досок, 10 камней и запас инструментов. Как в Settlers 4, запас на старте выбирается: «Мало», «Средне» (по умолчанию) или «Много» — кнопка ⟳ «Новая игра» в меню «Настройки» (там же размер карты и число соперников) или параметр `?start=low|medium|high`. У каждого игрока одинаковые гарантированные ресурсы: рядом с замком роща, две каменоломни, пруд и гора с углём и железом, а чуть дальше, за границей замка (нужна башня), — гора с камнем, золотом и ещё углём. Поэтому золото и уровни бойцов есть на картах любого размера.

**Инструменты.** Большинству профессий нужен свой инструмент: лесорубу топор, пильщику пила, каменотёсу и шахтёру кирка, фермеру коса, рыбаку удочка, строителю молоток, землекопу лопата, мяснику топор, охотнику лук; лесничему инструмент не нужен, геолог берёт молоток с собой и приносит его обратно. Носильщик сначала забирает инструмент со склада и только потом становится работником; нет инструмента — здание ждёт (это видно в информации о здании). На старте в замке есть запас инструментов, дальше их делает инструментальщик. Инструментальщик сам куёт то, чего не хватает, а в его окне можно заказать нужный инструмент: +1, +5 или «∞» (ковать без остановки) — заказанное куётся первым.

**Рабочие и распределение (меню «Поселенцы» и «Товары» в левой панели).** Как в Settlers 4, строителей и землекопов не прибавляется само собой: сколько их нужно, заказывает игрок (+1 / +5), и столько носильщиков берут молоток или лопату. Там же — распределение товаров: для зерна, воды, угля, железа и еды шахтёров можно задать, какую долю получает каждый вид зданий (например, всё зерно — мельнице, ничего — свиноферме). В окне склада переключателями выбирается, какие товары он принимает.

Экономика работает сама: носильщики подносят материалы на стройки и сырьё в мастерские, излишки уносят в замок. Свободные носильщики, как в Settlers 4, не прячутся в замке, а стоят небольшими группами у замка, складов и домов, прохаживаются и болтают парами — и сразу берутся за работу, как только она появится. Дефицитное сырьё делится между потребителями поровну — например, зерно между мельницей и свинофермой, — если в меню «Товары» → «Распределение» не задано иначе. Где поселенцы ходят часто, трава вытаптывается в **тропу**, потом в **дорогу**: по ним ходят быстрее, а без движения они зарастают. Готовое здание занимает свободный носильщик и становится его работником, поэтому для новых зданий нужны дома.

**Своя земля, ослы и рынок.** Как в Settlers 4, носильщики носят товары только по своей земле: между зданиями одного связного куска территории. Если земля разорвана (застава за чужой или ничейной землёй, захваченная башня вдали), до отрезанного куска носильщики не донесут ничего — такие здания помечены значком сломанной дороги, а в их окне написано «отрезано от складов». Туда товары возят ослы: постройте рынок на большой земле и рынок на отрезанном куске, задайте маршрут и заказ — ослы с ослиной фермы понесут по 4 штуки за раз, а на месте их разнесут носильщики (если там никого нет, один носильщик сам перейдёт туда).

**Солдаты и бой.** Бойцы бывают двух видов: мечник (меч, крепче в ближнем бою) и лучник (лук, стреляет издалека на 5 клеток, но слабее врукопашную). Они живут в гарнизонах, и места в них, как в Settlers 4, разделены по видам: в башне 1 мечник и 2 лучника, в большой башне 3 и 3, в крепости 4 и 5, в замке (это ваш штаб и резерв армии) 7 и 5; на старте в замке 6 мечников. Мечник не займёт место лучника, и наоборот. Пустые места заполняются бойцами из резерва замка; новых бойцов готовит только казарма: без неё мечи и луки просто лежат на складе. Сначала каждая пустая башня получает хотя бы одного бойца, потом тыловые здания отдают лишних в передовые, ближе к врагу.

**Оборона.** У каждого военного здания есть неприкосновенный минимум гарнизона: эти бойцы никогда не уходят ни в другие башни, ни в атаку (замок держит 4, крепость 3, большая башня 2, башня 1). Защитники у своей двери бьют сильнее (бонус обороны здания), лучники гарнизона обстреливают подходящих врагов. Раненые лечатся только в лазарете.

**Уровни.** Как в Settlers 4, уровень бойца выбирается при наборе в казарме и потом не меняется: уровень 1 — только оружие, уровень 2 — плюс 1 золото, уровень 3 — плюс 2 золота (казарма сама заказывает золото). Не хватает золота — новобранец выходит с тем уровнем, на который хватило. Каждый уровень даёт +30% к здоровью и силе удара; уровень виден шевронами над головой бойца, а состав гарнизона по видам и уровням — в информации о здании.

Чтобы атаковать, кликните по вражеской башне или замку: в информации видно число защитников, бонус обороны здания и сколько ваших свободных бойцов из военных зданий в радиусе 30 клеток можно послать (и кто пойдёт: мечники и лучники вперемешку); кнопками «−»/«+» выберите число и нажмите «⚔ Атаковать». У двери цели мечники по одному бьются с защитниками, а лучники поддерживают их стрелами; когда защитников не осталось, ваш мечник занимает здание (лучники захватывать не могут — они возвращаются в свои гарнизоны) — оно и его земля переходят к вам, а чужие мирные здания, оказавшиеся на вашей земле, сгорают. Спорная земля между военными зданиями достаётся ближайшему.

**Прямое управление.** Как в Settlers 3/4, бойцами можно командовать напрямую. Нажмите в окне своей башни «🚩 Вывести бойцов» — все сверх неприкосновенного минимума выйдут к двери. Обведите своих бойцов рамкой (левая кнопка мыши) или щёлкните по одному; Shift добавляет к выбору, двойной щелчок выбирает всех бойцов этого вида на экране. Выбранные обведены зелёными кольцами, а в левой панели — окно «Отряд»: сколько бойцов каждого вида и уровня, их здоровье и кнопки «Стоять», «В гарнизон», «Снять выбор». Правый щелчок отдаёт приказ: по земле — идти туда строем, по вражескому военному зданию — атаковать, по своему — войти в него. Бойцы в поле стоят, где поставлены, и сами нападают на врагов поблизости; лучники стреляют из поля, а лучники в башнях — по врагам у стен.

**Специалисты слушаются мыши так же.** Геологов, первопроходцев и воров можно обвести рамкой или выбрать щелчком — вместе с бойцами или отдельно. Правый щелчок даёт каждому подходящий приказ: геолог по своей горе идёт разведывать руду, первопроходец по ничейной земле у границы занимает её, вор по разведанному вражескому складу или замку идёт красть; в любом другом месте специалист просто идёт туда и ждёт. Рядом с курсором подсказка, что сделает правый щелчок. В окне «Отряд» специалисты считаются по видам, «✋ Стоять» останавливает их, «↩ Отпустить» возвращает в носильщики (только на своей земле).

**Командир отряда.** Оружейник, кроме мечей и луков, куёт доспехи (их долю задают в меню «Армия» или в окне оружейника). Казарма делает из доспеха и меча командира — бойца в шлеме с красным плюмажем. Он крепче мечника и тоже может захватывать здания, а бойцы рядом с ним (в 6 клетках) бьют на 15% сильнее. Отряд, построенный вокруг командира одним приказом, держит строй: пошлите одного командира — отряд пойдёт за ним.

**Сила армии.** Как в Settlers 4, на своей земле бойцы всегда сражаются в полную силу, а на чужой — с силой армии, которая видна в верхней строке. Она растёт с ценностью поселения: доски, брёвна и камень во всех готовых постройках, золото вдвое, а материалы украшений втрое; рост постепенно замедляется (до 150%). На старте при двух игроках это 50%, так что нападать на развитого соседа с бедным поселением тяжело. Защита на своей земле — 100%, а когда сила армии переваливает за 100%, растёт и она, вдвое медленнее.

**Компьютерный соперник.** Играет по тем же правилам, что и вы: строит те же здания из тех же материалов, посылает геологов, набирает солдат и лучников, добывает золото для обучения и расширяется самыми крупными башнями, которые может построить и занять, — сначала к ресурсам, потом к вам. Первые 25 минут он не нападает; дальше атакует, когда сила его свободных бойцов (с учётом уровней и его силы армии на чужой земле) заметно больше силы защитников цели с бонусом обороны (примерно 1,2 к 1). Посылает столько, сколько нужно с запасом, остальные остаются охранять его башни; на замок — всех. Выбирает цели, которые ведут к вашему замку, а найдя замок, стягивает к нему крупные башни и крепости, чтобы собрать кулак; после удачного захвата бьёт снова быстрее, пока вы не перегруппировались. Из лишнего камня и досок он строит украшения. Руду он видит только там, где побывали его геологи, а ваши здания — только там, где рассеялся его туман войны: пока он вас не нашёл, он ведёт башни в неразведанные земли, к центру карты; число защитников он знает, лишь пока здание в поле зрения его построек. Для рудника, которому не хватает руды, он посылает геологов и тянет башни к горам.

**Победа и поражение.** Кто потерял замок, выбывает: его поселенцы гибнут, а оставшиеся здания сгорают. Вы победили, когда взяты замки всех соперников, и проиграли, если взят ваш. В конце показывается итог партии с кнопками «Новая игра» и «Смотреть дальше».

Строить можно только на своей земле: она подсвечена, граница отмечена столбиками с кубиками цвета игрока (как в Settlers 4), а за ней земля затемнена. Добытчики, лесничие и фермеры тоже работают только в своих границах, так что за новыми лесами, каменоломнями и водой придётся расширяться башнями. Поля проходимы, но строить на них нельзя.

Земля не плоская: трава слегка холмистая, горы поднимаются над равнинами, а вода лежит ниже всего. С гор к морю текут реки (на больших картах горы тянутся хребтами), а на реках через каждые несколько клеток есть броды — мелководье, по которому можно перейти. Границы между водой, песком, травой и горами плавные.

Вдали от воды встречаются **пустыни**: по ним можно ходить и на них можно строить, но там ничего не растёт — ни деревья, ни поля. В низинах у воды бывают **болота**: как в Settlers 4, они непроходимы, на них нельзя строить и сажать. Земля при этом никогда не разрезана: через болота проложены сухие тропы, через сплошной лес — просеки. Вокруг замка ни пустынь, ни болот нет.

**Туман войны.** Сначала вы видите только окрестности замка, остальная карта чёрная. Земля открывается вокруг ваших зданий (военные видят дальше своей земли) и вокруг поселенцев, которые ходят по ней. Однажды увиденное остаётся на карте, но если там сейчас никого из ваших нет, местность затемнена: чужих поселенцев там не видно, а у вражеских зданий не видно гарнизона. Мини-карта показывает то же самое. Компьютерный соперник пока видит всю карту.

Дома выпускают тем больше жителей, чем больше карта: на 64×64 малый, средний и большой дом дают 4, 8 и 14 носильщиков, а от 256×256 — как в Settlers 4, 10, 20 и 50.

Как в Settlers 4, пока выбрано здание для постройки, на карте точками отмечены все места, где оно помещается: **зелёные** — ровно, **жёлтые** — участок наклонный, сначала его выровняет землекоп. Каждую стройку сначала расчищает **землекоп** с лопатой (на старте их двое; больше — по заказу в меню «Поселенцы»), носильщики тем временем уже несут материалы, и только потом приходят строители (в информации о стройке видно «Выравнивание»). Слишком крутой склон «призрак» здания показывает красным. Шахтам землекоп не нужен. Флажок на крыше поднимается, когда здание заселено: в мастерскую пришёл работник, в башню — солдаты.

По горам можно ходить, но строить на них можно только шахты. Непроходимы лишь скальные вершины, усыпанные валунами.

По карте бродят дикие животные: олени у опушек, ослы и куры на лугах, утки у воды. Они живут сами по себе, никому не мешают и видны только там, где у вас есть обзор (позже на оленей будет охотиться охотник).

Деревья растут в четыре стадии (рубить можно только взрослые), поля — тоже в четыре (убирать можно только спелые). Ни саженцы, ни самосев никогда не перекрывают проходы.

### Управление

| Действие | Клавиши / мышь |
|---|---|
| Двигать камеру | перетаскивание правой или средней кнопкой (левой — пока выбрано здание для постройки), WASD, стрелки, край экрана |
| Зум | колесо мыши |
| Выбрать здание для постройки | меню «Строительство» в левой панели (значки категорий, под ними здания с числом уже построенных); `Tab` — следующая категория, `1`–`9` — здание открытой категории |
| Поставить | ЛКМ (с Shift — несколько подряд) |
| Отменить постройку | ПКМ или Esc |
| Выбрать бойцов и специалистов | рамка левой кнопкой или щелчок по своему бойцу, геологу, первопроходцу или вору; Shift — добавить, двойной щелчок — все этого вида на экране; Esc — снять выбор |
| Приказ выбранным | ПКМ: бойцы — по земле идти, по вражескому военному зданию атаковать, по своему войти в гарнизон; геолог — по своей горе разведать руду; первопроходец — по ничейной земле у границы занять её; вор — по разведанному вражескому складу украсть; иначе специалист идёт туда и ждёт. Подсказка у курсора показывает, что произойдёт |
| Окно поселенца | клик по человечку: в левой панели его портрет, кто он, чей и чем занят (несёт, строит, рубит, идёт в гарнизон…), у бойцов уровень и здоровье, у первопроходца и вора — «Послать…» и «↩ Отпустить»; над ним на карте метка; × или Esc — закрыть |
| Окно здания | клик по зданию: окно с картинкой здания открывается в левой панели вместо меню, как в Settlers 4; там же «⬆ Приоритет», «🔨 Снести» (по второму клику), атака, доли оружия, уровень новобранцев, заказы инструментальщика, товары склада; × или Esc — закрыть |
| Пауза / скорость | пробел, кнопки справа вверху (пауза, 1× / 2× / 4×) или меню «Настройки» |
| Меню | круглые кнопки-самоцветы под мини-картой: Строительство, Товары (склад и распределение), Поселенцы (специалисты и заказ рабочих), Статистика, Армия (сила, бойцы, уровень новобранцев, доли оружия), Настройки |
| Мини-карта | вверху левой панели; клик переносит камеру. Внизу панели — запасы главных товаров, число поселенцев и бойцов, сила армии |
| Сохранить / загрузить | меню «Настройки» (одна ячейка сохранения в браузере); там же «Новая игра» |
| Звук | меню «Настройки»: 🔊 — выключить/включить (или `M`), ползунок — громкость, ♫ — музыка |

### Звук

Звук включается после первого клика или нажатия клавиши (так требуют браузеры). Слышно то, что видно на экране: стук топоров и молотов, кирки, пилу, плеск воды, падение деревьев, звон мечей и тетиву луков, сигнал готовой стройки. Чем дальше от центра экрана, тем тише, а слева и справа звук идёт из соответствующей колонки. Фоном играет спокойная музыка и поют птицы. Громкость, выключение звука и музыки запоминаются в браузере.

## Технологии

- **TypeScript + Vite** — сборка и dev-сервер.
- **PixiJS 8** — рендер на WebGL.
- **Vitest** — тесты симуляции.

Все спрайты (земля, деревья, здания, поселенцы) рисуются кодом на Canvas 2D при старте и собираются в текстурный атлас, а все звуки синтезируются на WebAudio, поэтому внешних картинок и звуковых файлов нет.

## Структура

```
src/sim/      симуляция без зависимостей от браузера: карта, A*, поселенцы, здания, логистика
src/render/   изометрический рендер на PixiJS, генерация спрайтов, анимации и эффекты, камера
src/audio/    синтез звуков, музыка, громкость и позиционирование
src/ui/       HTML-интерфейс, ввод, общее состояние
tests/        тесты симуляции
docs/         спецификация прототипа
```

Симуляция идёт фиксированными тиками (10 в секунду) и детерминирована по сиду, рендер только читает её состояние и сглаживает движение между тиками. Подробнее об устройстве кода — в [CLAUDE.md](CLAUDE.md) и в [исходной спецификации прототипа](docs/superpowers/specs/2026-10-06-settlers-prototype-design.md) (историческая, описывает самую первую версию).

## Команды

```bash
npm run dev         # dev-сервер
npm test            # тесты
npm run typecheck   # проверка типов
npm run build       # production-сборка в dist/
npm run sim:probe   # проверка экономики: час игры на нескольких картах
npm run sim:bench   # замер скорости симуляции: карта 256×256, 1000 поселенцев
npm run sim:ai      # компьютер против компьютера (или против пассивного игрока: --passive=1) на час игры
npm run art:render  # перерендерить 3D-спрайты в public/art/3d (нужен Blender; можно перечислить: -- settlers tree)
npm run art:ground  # пересоздать фактуры земли всех видов, поля и тропы в public/art/3d (нужен Blender)
npm run art:animals # перерендерить листы животных в public/art/3d (нужен Blender; можно: -- deer duck)
```
