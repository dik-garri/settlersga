# Settlers — браузерный прототип

Прототип экономической стратегии в духе The Settlers 3/4: изометрическое 2D, спрайты, поселенцы, которые сами рубят лес, пилят доски и строят дома. Всё работает в браузере без установки.

![Скриншот](docs/screenshot.jpg)

## Запуск

Нужен Node.js 20.19+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Карта генерируется случайно; чтобы сыграть на той же карте ещё раз, добавьте к адресу `?seed=42` (сид текущей карты пишется в консоль браузера). Размер карты задаётся параметром `?size=128` (по умолчанию 64).

## Как играть

На старте есть замок со складом, 12 носильщиков, 3 строителя, 20 досок и 10 камней. Рядом с замком всегда есть роща, каменоломня и пруд.

Здания сгруппированы во вкладки меню строительства:

| Вкладка | Здание | Стоимость | Что делает |
|---|---|---|---|
| Жильё | Малый / средний / большой дом | 2🪚 1🪨 / 3🪚 2🪨 / 5🪚 4🪨 | Постепенно выпускает 4 / 8 / 14 новых носильщиков. Только так растёт население — замок поселенцев не рождает |
| Сырьё | Дом лесоруба | 2🪚 | Рубит зрелые деревья в радиусе 8 клеток |
| | Дом лесничего | 2🪚 | Сажает деревья в радиусе 6, чтобы лес не кончался |
| | Лесопилка | 2🪚 2🪨 | Бревно → доска |
| | Каменотёс | 2🪚 | Добывает камень из глыб в радиусе 8; камень конечен |
| Еда | Водокачка | 2🪚 | Черпает воду с берега (вода бесконечна) |
| | Рыбак | 2🪚 | Ловит рыбу с берега; запас рыбы в воде восполняется |
| | Ферма | 3🪚 1🪨 | Засевает поля вокруг себя и собирает созревшее зерно |
| | Мельница | 3🪚 2🪨 | Зерно → мука |
| | Пекарня | 2🪚 2🪨 | Мука + вода → хлеб |
| | Свиноферма | 3🪚 1🪨 | Зерно + вода → свинья |
| | Бойня | 2🪚 2🪨 | Свинья → 2 мяса |
| Военное | Сторожевая башня | 2🪚 3🪨 | С заселившимся стражником расширяет землю на 8 клеток |

Экономика работает сама: носильщики подносят материалы на стройки и сырьё в мастерские, излишки уносят в замок. Дефицитное сырьё делится между потребителями поровну — например, зерно между мельницей и свинофермой. Готовое здание занимает свободный носильщик и становится его работником, поэтому для новых зданий нужны дома.

Строить можно только на своей земле: она подсвечена, а за синей границей земля затемнена. Добытчики, лесничие и фермеры тоже работают только в своих границах, так что за новыми лесами, каменоломнями и водой придётся расширяться башнями. Поля проходимы, но строить на них нельзя.

Деревья растут в четыре стадии (рубить можно только взрослые), поля — тоже в четыре (убирать можно только спелые). Ни саженцы, ни самосев никогда не перекрывают проходы.

### Управление

| Действие | Клавиши / мышь |
|---|---|
| Двигать камеру | перетаскивание мышью, WASD, стрелки, край экрана |
| Зум | колесо мыши |
| Выбрать здание для постройки | кнопки внизу; `Tab` — следующая вкладка, `1`–`9` — здание на открытой вкладке |
| Поставить | ЛКМ (с Shift — несколько подряд) |
| Отменить постройку | ПКМ или Esc |
| Информация о здании | клик по зданию |
| Пауза / скорость | пробел, кнопки 1× / 2× / 4× |
| Сохранить / загрузить | кнопки 💾 / 📂 справа вверху (одна ячейка сохранения в браузере) |

## Технологии

- **TypeScript + Vite** — сборка и dev-сервер.
- **PixiJS 8** — рендер на WebGL.
- **Vitest** — тесты симуляции.

Все спрайты (земля, деревья, здания, поселенцы) рисуются кодом на Canvas 2D при старте и собираются в один текстурный атлас, поэтому внешних картинок нет.

## Структура

```
src/sim/      симуляция без зависимостей от браузера: карта, A*, поселенцы, здания, логистика
src/render/   изометрический рендер на PixiJS, генерация спрайтов, камера
src/ui/       HTML-интерфейс, ввод, общее состояние
tests/        тесты симуляции
docs/         спецификация прототипа
```

Симуляция идёт фиксированными тиками (10 в секунду) и детерминирована по сиду, рендер только читает её состояние и сглаживает движение между тиками. Подробнее об устройстве кода — в [CLAUDE.md](CLAUDE.md) и [спецификации](docs/superpowers/specs/2026-10-06-settlers-prototype-design.md).

## Команды

```bash
npm run dev         # dev-сервер
npm test            # тесты
npm run typecheck   # проверка типов
npm run build       # production-сборка в dist/
npm run sim:probe   # проверка экономики: час игры на нескольких картах
npm run sim:bench   # замер скорости симуляции: карта 256×256, 1000 поселенцев
```
