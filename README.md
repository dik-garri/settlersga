# Settlers — браузерный прототип

Прототип экономической стратегии в духе The Settlers 3/4: изометрическое 2D, спрайты, поселенцы, которые сами рубят лес, пилят доски и строят дома. Всё работает в браузере без установки.

![Скриншот](docs/screenshot.jpg)

## Запуск

Нужен Node.js 20.19+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Карта генерируется случайно; чтобы сыграть на той же карте ещё раз, добавьте к адресу `?seed=42` (сид текущей карты пишется в консоль браузера).

## Как играть

На старте есть замок со складом, 12 носильщиков, 3 строителя, 14 досок и 6 камней.

1. Поставьте **дом лесоруба** (2 доски) рядом с лесом — лесоруб будет рубить зрелые деревья в радиусе 8 клеток.
2. Поставьте **лесопилку** (2 доски + 2 камня) — она превращает брёвна в доски.
3. Поставьте рядом с лесорубом **дом лесничего** (2 доски) — лесничий сажает деревья в радиусе 6 клеток, и лес не кончается.
4. Поставьте **каменотёса** (2 доски) у каменных глыб — он добывает камень в радиусе 8 клеток. Одна каменоломня есть рядом с замком, остальные разбросаны по карте. Камень конечен: выработанная глыба исчезает, и место снова становится проходимым.
5. Когда станет тесно, поставьте у границы **сторожевую башню** (2 доски + 3 камня). Как только в неё заселится стражник, ваша земля расширится на 8 клеток вокруг башни.
6. Дальше экономика работает сама: носильщики подносят доски и камень на стройки, брёвна — на лесопилку, излишки уносят в замок. Готовое здание занимает свободный носильщик и становится его работником. Замок раз в 20 секунд выпускает нового носильщика (до 40 жителей).

Строить можно только на своей земле: она подсвечена, а за синей границей земля затемнена. Лесорубы, каменотёсы и лесничие тоже работают только в своих границах, так что за новыми лесами и каменоломнями придётся расширяться башнями.

Деревья растут в четыре стадии (рубить можно только взрослые) и понемногу разрастаются сами, но без лесничего вырубленный лес восстанавливается очень долго. Ни саженцы лесничего, ни самосев никогда не перекрывают проходы — деревья не замуруют здания и поселенцев.

### Управление

| Действие | Клавиши / мышь |
|---|---|
| Двигать камеру | перетаскивание мышью, WASD, стрелки, край экрана |
| Зум | колесо мыши |
| Выбрать здание для постройки | кнопки внизу или `1`–`5` |
| Поставить | ЛКМ (с Shift — несколько подряд) |
| Отменить постройку | ПКМ или Esc |
| Информация о здании | клик по зданию |
| Пауза / скорость | пробел, кнопки 1× / 2× / 4× |

## Технологии

- **TypeScript + Vite** — сборка и dev-сервер.
- **PixiJS 8** — рендер на WebGL.
- **Vitest** — тесты симуляции.

Все спрайты (земля, деревья, здания, поселенцы) рисуются кодом на Canvas 2D при старте и собираются в один текстурный атлас, поэтому внешних картинок нет.

## Структура

```
src/sim/      симуляция без зависимостей от браузера: карта, A*, поселенцы, здания, логистика
src/render/   изометрический рендер на PixiJS, генерация спрайтов, камера
src/ui/       HTML-интерфейс, ввод, общее состояние
tests/        тесты симуляции
docs/         спецификация прототипа
```

Симуляция идёт фиксированными тиками (10 в секунду) и детерминирована по сиду, рендер только читает её состояние и сглаживает движение между тиками. Подробнее об устройстве кода — в [CLAUDE.md](CLAUDE.md) и [спецификации](docs/superpowers/specs/2026-10-06-settlers-prototype-design.md).

## Команды

```bash
npm run dev         # dev-сервер
npm test            # тесты
npm run typecheck   # проверка типов
npm run build       # production-сборка в dist/
```
