# Settlers — ein Browser-Prototyp

[Русский](README.md) · [English](README.en.md) · **Deutsch**

Ein Prototyp einer Wirtschaftsstrategie im Geiste von The Settlers 3/4: isometrisches 2D, Sprites und Siedler, die selbst Bäume fällen, Bretter sägen und Häuser bauen. Alles läuft im Browser, ohne Installation. Die Oberfläche gibt es auf Russisch, Englisch und Deutsch (wählbar in den Einstellungen).

![Bildschirmfoto](docs/screenshot.jpg)

**Im Browser spielen:** https://dik-garri.github.io/settlersga/ (wird bei jedem Push nach `main` automatisch gebaut und veröffentlicht).

## Systemanforderungen

Keine Installation — nur ein Browser. Auf schwachen Rechnern wurde das Spiel nicht gemessen, das Minimum unten ist daher eine Schätzung.

- **Browser:** ein aktueller mit **WebGL 2** — Chrome / Edge 90+, Firefox 90+, Safari 15+ (praktisch alles seit 2021). Ton läuft über WebAudio und startet nach dem ersten Klick. Auf Handys öffnet sich das Spiel, die Steuerung ist aber für Maus und Tastatur gedacht.
- **Download:** einmalig etwa 10 MB (≈ 9 MB Grafik, ≈ 1 MB Code), danach aus dem Browser-Cache. Spielstände liegen im Browser, ≈ 150 KB pro Partie auf 256 × 256.

| | Minimum (Schätzung) | Komfortabel |
|---|---|---|
| Prozessor | 2 Kerne (aktueller Intel Core i3 / AMD Ryzen 3) | 4 Kerne und mehr |
| Arbeitsspeicher | 4 GB (der Tab braucht ≈ 300–600 MB) | 8 GB |
| Grafik | integrierte Grafik mit WebGL 2 (Intel UHD 620, Apple M1 u. ä.) | jede aktuelle dedizierte oder integrierte |
| Bildschirm | 1280 × 720 | 1920 × 1080 und mehr (Retina wird unterstützt) |

Am stärksten wirken Kartengröße und Spielerzahl: Karten 64–128 sind leicht, 512 und 1024 deutlich schwerer, besonders bei 2× / 4×. Zum Vergleich: Auf Apple Silicon rechnet eine 256 × 256-Karte mit 1000 Siedlern einen Spielschritt in ≈ 0,7 ms — etwa 15-mal schneller als nötig. Gezeichnet wird nur, was auf dem Bildschirm ist; ferne Kartenteile werden entladen. **Wenn es ruckelt:** kleinere Karte, kein 4×-Tempo, die klassische Grafik `?art=classic` (schont die Grafikkarte) oder andere Tabs schließen.

## Start

Benötigt wird Node.js 20.19+.

```bash
npm install
npm run dev
```

Öffnet die Adresse, die Vite anzeigt. Bei jedem Start läuft ein kurzes Intro (ein Klick — mit Ton beginnen, noch ein Klick oder eine beliebige Taste — überspringen; abschaltbar in den Einstellungen), danach folgt das **Hauptmenü**, wie in Settlers 4, aber mit eigener Gestaltung und Musik; dahinter lebt eine Siedlung, die der Computer selbst aufbaut:
- **Tutorial** — an erster Stelle, wie in Settlers 4: kurze Missionen, die Schritt für Schritt durch das Spiel führen. Der Text des Schritts, die Knöpfe „Weiter“, „Zeigen“ und „Tipp“ und die Liste der Ziele stehen in einer Leiste oben links, der zu drückende Knopf leuchtet auf, ein Pfeil zeigt den Ort auf der Karte, und was die Mission noch nicht erreicht hat, ist im Baumenü grau mit einem Schloss. Fertig sind „Holz und Stein“ (Kamera, Waren auf dem Boden, die ersten Bauten: Holzfäller, Sägewerk, Steinmetz, Förster), „Lager, Häuser und Träger“ (das Lagerhaus und was es annimmt, Betten und Streik, Vorrang, Anhalten, Transportreihenfolge, Trägerreserve), „Brot für die Bergleute“ (Fischer, Wasserwerk, die Farm und ihr Arbeitsgebiet, Mühle, Bäckerei, Brotverteilung, Nahrung für eine Mine) und „Geologe, Minen und Schmieden“ (der Geologe und seine Schilder, Meldungen und Leertaste, Minen auf Erz, die Schmelze, Werkzeugaufträge); zwei weitere — Markt und Esel, die erste Schlacht — sind als „bald“ markiert. Geschaffte Missionen bekommen einen Haken; eine Mission lässt sich speichern und vom selben Schritt aus fortsetzen. Am Ende folgt eine Bilanz: „Nächste Mission“, „Auf der Karte bleiben“ (danach freies Spiel) oder „Hauptmenü“.
- **Neues Spiel** — die Partie einrichten: Kartengröße (64–512, Standard 128 × 128 — die kleine Zwei-Spieler-Karte von Settlers 4; für drei oder vier Spieler passt 192, für mehr 320), Kartennummer (leer — zufällig; dieselbe Nummer ergibt immer dieselbe Karte), Startvorräte, Nebel des Krieges und vier Spielerplätze. Für jeden Platz wählt Ihr, wer spielt (Ihr, der Computer oder „Geschlossen“), das Volk (vorerst nur die Römer, die übrigen kommen mit den weiteren Völkern), das Team (ein Team sind Verbündete: sie kämpfen nicht gegeneinander, sehen das Land der anderen und siegen gemeinsam) und die Stärke des Computers: **Leicht** (denkt halb so oft nach, greift später und nur mit großer Überlegenheit an), **Mittel** oder **Schwer** (denkt öfter nach, greift früher und kühner an, betreibt mehr Baustellen gleichzeitig); wie in Settlers 4 bekommt der Computer Vergünstigungen — unerschöpfliche Minen, zusätzliche Bretter, Steine und Pioniere (ab „Mittel“ auch Schwertkämpfer) zum Start und doppelte Kampfkraft aus seinen Gebäuden. Das Menü merkt sich die letzte Einstellung.
- **Laden** — eine Liste der Spielstände mit Datum, Kartengröße, Spielerzahl und Spielzeit; jeder lässt sich laden oder löschen.
- **Netzwerkspiel** — vorerst nur das Aussehen der künftigen Lobby (derselbe Einrichtungsbildschirm, Plätze für Netzwerkspieler); das Netzwerkspiel selbst kommt bald.
- **Einstellungen** — Sprache (Russisch, Englisch, Deutsch; wechselt sofort, im Menü wie in der Partie — standardmäßig die Sprache des Browsers, wenn sie Englisch oder Deutsch ist, sonst Russisch), Ton, Musik, Darstellung (3D oder klassisch), ob das Intro beim Start gezeigt wird (standardmäßig ja); **Über das Spiel**; **Beenden** — zurück zum Intro. Aus einer Partie führt „Beenden“ direkt ins Hauptmenü.

**Im Spiel** öffnet Esc (wenn nichts ausgewählt ist) oder „Menü“ in den Optionen der linken Leiste das Spielmenü, und das Spiel pausiert: „Weiterspielen“, „Speichern“ (ein neuer Spielstand mit Namen oder ein alter wird überschrieben), „Laden“, „Einstellungen“, „Zum Hauptmenü“. Spielstände sind unbegrenzt möglich, sie werden komprimiert im Browser gespeichert; alle 5 Spielminuten schreibt sich die Partie selbst in den Platz „Automatische Speicherung“.

Für die Entwicklung lässt sich eine Partie mit Adressparametern direkt starten, am Menü vorbei (`?menu` — trotzdem das Menü öffnen). Die Karte wird zufällig erzeugt; um dieselbe Karte noch einmal zu spielen, hängt `?seed=42` an die Adresse (den Seed der aktuellen Karte schreibt das Spiel in die Browserkonsole). Die Kartengröße setzt der Parameter `?size=192` (Standard 128; spielbar sind Karten bis `?size=1024`), die Spielerzahl `?players=1` (Standard 2: Ihr und ein Computergegner in der gegenüberliegenden Ecke der Karte; `?players=4` — Ihr und drei Computergegner, besser auf großen Karten). Mit `?teams=1,1,2,2` teilen sich die Spieler in Teams: Verbündete greifen einander nicht an, siegen gemeinsam und sehen alles, was der Verbündete sieht (gemeinsamer Nebel des Krieges). `?levels=medium,hard` setzt die Stärke des Computers je Spieler, `?load=1` lädt den letzten Spielstand. `?lang=en` (oder `de`, `ru`) öffnet das Spiel in dieser Sprache, ohne die Wahl in den Einstellungen zu ändern. Mit `?ai=off` bleiben die Gegner passiv, mit `?fog=off` ist der Nebel des Krieges aus (zum Debuggen). Für die Entwicklung gibt es die Demokarte **`?demo`** (zum Beispiel https://dik-garri.github.io/settlersga/?demo): sie baut sich in ein paar Sekunden selbst auf und zeigt alles auf einmal — alle Gebäude fertig und mit Arbeitern, Baustellen, eingefroren in jeder Bauphase, Stapel aller Waren, einen Geologen beim Erkunden und ein Feld seiner Schilder mit allen Erzen, einen Pionier an der Grenze und einen Dieb am Lagerhaus des zweiten Spielers, eine Truppe um einen Truppführer, Esel zwischen Märkten, Verwundete im Lazarett, alle Zierden; ohne Nebel (`?fog=on` — mit Nebel). Die gesamte Grafik ist standardmäßig im Stil von Settlers 4 und stammt aus Blender (`?art=classic` — die alte, per Code gezeichnete): Boden aller Arten (Strände, Wasser, Berge, Wüste, Sumpf), Fichten und Laubbäume, Grasbüschel, Blumen und Pilze auf den Wiesen, Äcker und Pfade, alle Gebäude (mit Bauphasen: Pflöcke, Gerüst oder Fundament, Mauern, Dach), Steine, Stapel aller Waren vor den Türen (so viele, wie daliegen, sind auch zu sehen; mehr als acht — der nächste Stapel daneben), alle Siedler und Soldaten (3D-Figuren in einer Tunika in der Spielerfarbe, mit dem Werkzeug ihres Berufs). Die Soldaten sind wie römische Legionäre gekleidet und sofort von den Zivilisten zu unterscheiden: der Schwertkämpfer mit Stahlhelm, Schienenpanzer und großem gewölbtem Schild in der Spielerfarbe, der Bogenschütze mit Helm, Lederrüstung und Köcher, der Truppführer ganz in Gold: vergoldeter Helm mit hohem Kamm, Kürass, runder goldener Schild und Umhang.

## Wie man spielt

Wie in Settlers 4 gibt es kein Hauptquartier: zu Beginn habt Ihr einen einzigen Wachturm (darin ein Schwertkämpfer; die übrigen Startkämpfer stehen frei daneben, und jeder neue Turm ruft einen von ihnen) und die Leute der Römer aus Settlers 4 — auf „Mittel“ 32 Träger, 5 Bauarbeiter, 5 Planierer, 10 Schwertkämpfer und 4 Bogenschützen, 3 Geologen (warten auf Befehle), 2 Schmiede und 4 Bergleute (warten auf ihre Werkstatt und ihre Mine und beziehen sie als Erste, ohne Werkzeug aus dem Lager; ein Schmied geht sowohl in die Werkzeugschmiede als auch in die Waffenschmiede); auf „Wenig“ 16 Träger, je 3 Bauarbeiter und Planierer, 6 Schwertkämpfer, 2 Bogenschützen, 2 Geologen, ein Schmied und 2 Bergleute; auf „Viel“ 50 Träger, je 2 Bauarbeiter und Planierer (die Hämmer und Schaufeln in den Stapeln reichen für noch zwei Dutzend), 12 Schwertkämpfer, 6 Bogenschützen, 5 Geologen, 3 Schmiede, 6 Bergleute, ein Jäger und 3 Esel. Die Waren liegen rund um den Turm auf dem Boden, in Stapeln zu bis zu 8 Stück — dieselben Stapel wie bei den Römern in Settlers 4: auf „Mittel“ 27 Bretter, 27 Steine, 7 Schaufeln, 8 Hämmer, 5 Äxte, 4 Spitzhacken, 2 Sägen, eine Angel, eine Sense, etwas Fisch, Brot, Fleisch, Kohle und Eisenerz. Die Träger nehmen sie direkt vom Boden für Baustellen und Werkstätten; ins Lagerhaus bringen sie nur, was das Lagerhaus annimmt. Wie in Settlers 4 sind die Startvorräte wählbar: „Wenig“, „Mittel“ (Standard) oder „Viel“ — im Bildschirm „Neues Spiel“ des Hauptmenüs (dort auch Kartengröße, Gegner, Verbündete und Stärke) oder mit dem Parameter `?start=low|medium|high`. Jeder Spieler hat dieselben garantierten Rohstoffe: nahe dem Startplatz ein Wäldchen, zwei Steinbrüche, einen Teich und einen Berg mit Kohle und Eisen, etwas weiter, jenseits der Grenze des Startturms (dafür braucht es noch einen Turm), einen Berg mit Stein, Gold und weiterer Kohle. Deshalb gibt es Gold und Kämpferstufen auf Karten jeder Größe.

Die Gebäude sind in Reiter des Baumenüs gruppiert:

**Werkzeuge.** Die meisten Berufe brauchen ihr eigenes Werkzeug: der Holzfäller eine Axt, der Säger eine Säge, Steinmetz und Bergmann eine Spitzhacke, der Bauer eine Sense, der Fischer eine Angel, der Bauarbeiter einen Hammer, der Planierer eine Schaufel, der Metzger eine Axt, der Jäger einen Bogen; der Förster braucht kein Werkzeug; Geologe, Pionier (Schaufel) und andere bestellte Arbeiter legen ihr Werkzeug, wenn sie entlassen werden, neben sich auf den Boden (wie in Settlers 4) — von dort wird es abgeholt. Ein Träger holt zuerst das Werkzeug (aus dem Lagerhaus, vom Stapel an einer Werkstatt oder von einem Stapel auf dem Boden) und wird erst dann zum Arbeiter; fehlt das Werkzeug, wartet das Gebäude (das steht in der Gebäudeinformation). Zu Beginn liegen die Werkzeuge beim Turm auf dem Boden, danach stellt sie die Werkzeugschmiede her. Der Werkzeugschmied schmiedet von selbst, was fehlt, und in seinem Fenster lässt sich das gewünschte Werkzeug bestellen: +1, +5 oder „∞“ (ohne Ende schmieden) — Bestelltes wird zuerst geschmiedet.

**Arbeiter und Verteilung (Menüs „Siedler“ und „Waren“ in der linken Leiste).** Wie in Settlers 4 werden Bauarbeiter, Planierer und Spezialisten (Geologen, Pioniere, Diebe) nicht von selbst mehr: wie viele es braucht, bestellt der Spieler (+1 / +5), und so viele Träger nehmen einen Hammer oder eine Schaufel; „↩“ entlässt einen freien wieder zu den Trägern; senkt Ihr die Bestellung von Bauarbeitern oder Planierern, werden die überzähligen, sobald sie frei sind, ebenfalls zu Trägern und legen Hammer oder Schaufel auf den Boden. Darüber steht die **Trägerreserve** (Standard 5, wie in Settlers 4): solange es nicht mehr Träger als die Reserve gibt, wird keiner von ihnen Arbeiter, Bauarbeiter, Planierer, Spezialist oder Rekrut — irgendwer muss ja tragen. Im Menü „Waren“ steht die Warenverteilung: für Getreide, Wasser, Kohle, Eisen und die Nahrung der Bergleute lässt sich einstellen, welchen Anteil jede Gebäudeart bekommt (zum Beispiel alles Getreide an die Mühle, nichts an die Schweinezucht). Im Fenster eines Lagerhauses liegen die Waren in zwei Listen — „Nimmt an“ und „Nimmt nicht an“ — als große Symbole mit Bestand; ein Klick auf eine Ware verschiebt sie in die andere Liste, die Knöpfe „alle“ / „keine“ verschieben alles auf einmal. Auf der Seite „Transport“ des Menüs „Waren“ steht die **Transportreihenfolge**, wie in Settlers 4 (standardmäßig die römische: Brett, Stein, Baumstamm, Eisen, Erz, Kohle, Nahrung…): wenn Träger fehlen, werden Waren weiter oben in der Liste zuerst befördert; Pfeile schieben eine Ware einen Platz höher oder tiefer, an den Anfang oder ans Ende. Träger, die eine Ware zu einem Lagerhaus tragen, das sie nicht mehr annimmt, wenden zum nächsten Lagerhaus auf demselben Land, das sie annimmt und Platz hat (gibt es keines, bringen sie sie trotzdem hin — nichts geht verloren).

**Betten und Streik.** Wie in Settlers 4 braucht jeder Träger ein Bett: zu Beginn gibt es 30 / 50 / 60 (Wenig / Mittel / Viel), und jedes fertige Wohnhaus bringt so viele Betten, wie es Bewohner hervorbringt (10, 20, 50). Arbeiter, Spezialisten und Kämpfer brauchen kein Bett. Gibt es mehr Träger als Betten (zum Beispiel, weil ein Wohnhaus abgerissen wurde oder sein Land abgebrannt ist), **streiken** die überzähligen freien Träger: sie stehen herum und nehmen keine Arbeit an. Im Menü „Siedler“ sind „Betten (Träger)“ und die Zahl der Streikenden zu sehen, und im Meldungsband erscheint eine Warnung; ein neues Wohnhaus nimmt zuerst die Streikenden auf (und bringt entsprechend weniger neue Bewohner hervor).

**Arbeitslose.** Wie in Settlers 4 wird der Arbeiter eines abgerissenen oder abgebrannten Gebäudes nicht zum Träger: er bleibt Holzfäller, Bergmann usw. mit seinem Werkzeug und wartet bei den Häusern, und das nächste neue Gebäude seines Handwerks nimmt ihn als Ersten — ohne neues Werkzeug. Wie viele es sind, zeigt die Zeile „Ohne Arbeit“ im Menü „Siedler“. Zurück zum Träger machen lässt sich ein Arbeiter nicht (in Settlers 4 auch nicht — nur Spezialisten).

**Gebäude anhalten.** Der Knopf „⏸ Anhalten“ im Fenster einer Werkstatt, einer Sammlerhütte, einer Mine, einer Farm, der Kaserne, eines Lagerhauses, eines Marktes oder einer Baustelle, wie in Settlers 4: das Gebäude beendet die begonnene Arbeit und tut danach nichts mehr und fordert nichts mehr an, und die Waren an seiner Tür tragen die Träger dorthin, wo sie gebraucht werden (oder ins Lagerhaus); eine Baustelle entlässt Bauarbeiter und Planierer und gibt ihre Baustoffe an andere Baustellen ab; ein Lagerhaus nimmt keine Waren mehr an, gibt seine aber heraus; Esel, die zu einem angehaltenen Markt unterwegs waren, kehren zu dem Markt um, an dem sie beladen wurden, und laden dort ab. Über dem Dach eines angehaltenen Gebäudes (bei einer Baustelle über ihrer aktuellen Bauphase) erscheint ein Pausensymbol; „▶ Fortsetzen“ stellt alles wieder her. Ein Wohnhaus lässt sich nicht anhalten.

**Lagerhäuser sind nicht bodenlos.** Wie in Settlers 4 liegen die Waren im Lagerhaus in Stapeln zu 8 Stück, ein Lagerhaus hat 8 Stapel (64 Dinge). Ein neues Lagerhaus nimmt zunächst nichts an: in seinem Fenster gibt es zwei Listen, „Nimmt an“ und „Nimmt nicht an“, ein Klick auf eine Ware verschiebt sie in die andere Liste. Im Fenster steht, wie viel belegt ist: „Belegt 40 / 64“, „Stapel 5 von 8“, bei jeder Ware die Anzahl und wie viele Stapel sie belegt. Ein Träger wird nur dorthin geschickt, wo für seine Last schon Platz ist (Dinge unterwegs zählen mit), deshalb verteilen sich die Träger auf verschiedene Lagerhäuser. Wenn auf eigenem Land nirgends mehr Platz ist, bleiben die Überschüsse beim Erzeuger: sein Stapel an der Tür wächst bis 8, und er hält an — wie im Original, bis Ihr noch ein Lagerhaus baut oder Verbraucher die Ware abholen (sie nehmen sie direkt beim Erzeuger). Ein Ding, das ein Träger schon in den Händen hält (zum Beispiel, wenn seine Baustelle abgerissen wurde), geht nicht verloren: er legt es dort auf den Boden, wo er steht, und es wird später aufgesammelt wie jeder Stapel.

**Waren auf dem Boden.** Stapel auf dem Boden (Startwaren, Reste abgerissener und abgebrannter Gebäude, fallen gelassene Lasten) — bis zu 8 Stück einer Ware auf einem Feld. Beim Gehen stören sie nicht (sie werden nur umgangen, wenn möglich: wie in Settlers 4 ist der Weg über einen Stapel mehr als doppelt so teuer), aber auf diesem Feld lässt sich nichts bauen oder pflanzen, bis der Stapel abgetragen ist. Ein Stapel gehört dem, dem das Land gehört: nur dessen Träger nehmen ihn — für Baustellen und Werkstätten, und ins Lagerhaus nur, wenn irgendein Lagerhaus diese Ware annimmt. **Abriss** gibt wie in Settlers 4 die Hälfte der Bretter und Steine des Gebäudes zurück (bei einem unfertigen die Hälfte des schon Verbauten), und alles, was beim Gebäude lag (seine Stapel, der Bestand eines Lagerhauses, nicht verbaute Baustoffe einer Baustelle), bleibt vollständig auf dem Boden liegen. Feindliche Gebäude auf erobertem Land brennen ab, ohne Baustoffe zurückzugeben, aber ihre Waren bleiben liegen — und gehören Euch.

Die Wirtschaft läuft von selbst: Träger bringen Baustoffe zu den Baustellen und Rohstoffe in die Werkstätten und tragen Überschüsse in die Lagerhäuser, die sie annehmen (solange dort Platz ist). Freie Träger verstecken sich wie in Settlers 4 nicht in Lagerhäusern, sondern stehen in kleinen Gruppen bei Lagerhäusern und Wohnhäusern (solange es keine gibt — beim Turm), spazieren umher und plaudern paarweise — und machen sich sofort an die Arbeit, sobald welche anfällt. Rohstoffe, die Gebäude verschiedener Arten brauchen, werden gleichmäßig auf die Arten verteilt — zum Beispiel Getreide auf Mühle und Schweinezucht (Brot geht wie in Settlers 4 standardmäßig zu 85 % an die Kohleminen, der Rest gleichmäßig an die übrigen) —, sofern unter „Waren“ → „Verteilung“ nichts anderes eingestellt ist; unter Gebäuden derselben Art bekommt wie in Settlers 4 zuerst das, dessen Stapel kleiner und dessen Quelle näher ist, und fertige Werkstätten kommen vor Baustellen. Waren werden wie in Settlers 4 vor allem direkt beim Erzeuger abgeholt (sein Stapel zählt als halb so weit entfernt wie ein Lagerhaus), und ins Lagerhaus geht ein Überschuss, wenn sich beim Erzeuger mehr als ein Stück angesammelt hat. Wohnhäuser bringen Bewohner hervor, solange ein Spieler weniger als 2500 Siedler hat (bei fünf und mehr Spielern 10000 für alle zusammen). Wo Siedler oft gehen, wird das Gras zu einem **Pfad** und dann zu einem **Weg** festgetreten: Träger und Esel gehen darauf schneller (wie in Settlers 4; alle anderen wie auf Gras), und ohne Verkehr wachsen sie wieder zu. Das Spieltempo ist mit dem Original abgeglichen: Gehen, Bauen, die Arbeit von Werkstätten und Sammlern dauern genauso viele Sekunden wie in Settlers 4 (ein Holzfäller bringt etwa einen Baumstamm pro Minute, das Sägewerk sägt ein Brett in 19 Sekunden) — die Tabelle steht in [docs/TIMINGS.md](docs/TIMINGS.md) (auf Russisch). Auch die Proportionen der Welt sind wie in S4: unser Feld ist dreimal so lang wie ein S4-Feld, deshalb gehen die Siedler im Schritttempo — etwa ein halbes Feld pro Sekunde —, und Gebäudekosten, Land- und Arbeitsradien sind aus S4 übernommen und auf unser Feld umgerechnet ([docs/PROPORTIONS.md](docs/PROPORTIONS.md), auf Russisch). Ein fertiges Gebäude bezieht ein freier Träger und wird sein Arbeiter, deshalb braucht es für neue Gebäude Wohnhäuser.

**Eigenes Land, Esel und Markt.** Wie in Settlers 4 tragen Träger Waren nur über eigenes Land: zwischen Gebäuden auf einem zusammenhängenden Stück Territorium — und unterwegs kürzen sie nicht über fremdes oder herrenloses Land ab (ebenso gehen Bauarbeiter, Planierer und Arbeiter). Ist das Land zerrissen (ein Außenposten jenseits fremden oder herrenlosen Landes, ein eroberter Turm in der Ferne), bringen die Träger nichts zum abgeschnittenen Stück — solche Gebäude tragen das Symbol einer unterbrochenen Straße, und in ihrem Fenster steht „von den Lagerhäusern abgeschnitten“. Dorthin bringen Esel die Waren: baut einen Marktplatz auf dem großen Land und einen auf dem abgeschnittenen Stück, legt die Route fest und klickt die gewünschten Waren in die Liste „Befördert“ — Esel aus der Eselzucht tragen je zwei Packen zu 8 Stück (16 einer Ware oder je 8 von zwei verschiedenen; ein Esel wartet auf volle Ladung, solange die Ware noch gebracht wird), und vor Ort verteilen sie die Träger (ist dort niemand, geht ein Träger von selbst hinüber). Nach dem Abladen kehrt der Esel wie in Settlers 4 dorthin zurück, wo er angeheuert wurde, wenn das auf demselben Land liegt.

**Soldaten und Kampf.** Es gibt zwei Arten von Kämpfern: den Schwertkämpfer (Schwert, ein kräftiger Nahkämpfer) und den Bogenschützen (Bogen, schießt aus 3 Feldern Entfernung, aus einem Turm 6–7, ist aber schwächer und trifft seltener). Die Plätze in Militärgebäuden sind wie in Settlers 4 nach Art getrennt: im Wachturm 1 Schwertkämpfer und 2 Bogenschützen, im Großen Turm 3 und 3, in der Burg 4 und 5; ein Schwertkämpfer nimmt keinen Platz eines Bogenschützen ein und umgekehrt. **Die Besatzung funktioniert wie in Settlers 4:** ein fertiger Turm ruft von selbst **einen** freien Kämpfer (einen Schwertkämpfer, und wenn es keinen freien Schwertkämpfer gibt, einen Bogenschützen), die übrigen Plätze auf Euren Befehl. Im Fenster des Turms steht, wie viele Kämpfer jeder Art drin sind und wie viele eingestellt sind; „⬆ Auffüllen“ ruft Kämpfer auf alle Plätze, „−“/„+“ bei Schwertkämpfern und Bogenschützen ändern die Zahl um eins (mindestens ein Kämpfer bleibt im Turm), „⬇ Abziehen“ behält einen, die übrigen treten einzeln heraus — und nur, solange kein Feind in der Nähe ist. Einen Kämpfer, den Ihr selbst in den Turm geschickt habt, behält der Turm. Der Turm ruft beliebige eigene Kämpfer von draußen — wie in Settlers 4 auch die, die auf Euren Befehl stehen oder zum Angriff ziehen (außer den kämpfenden) —, zuerst die mit der höchsten Stufe, zuerst die nächsten (bis ≈ 7, dann 13, dann 27 Felder). Gibt es keine freien, bleibt der Turm leer, hält kein Land, und es kommt die Meldung „steht leer: keine freien Kämpfer“. Von Turm zu Turm wechseln Kämpfer nicht von selbst. Zu Beginn („Mittel“) steht im Wachturm ein Schwertkämpfer, die übrigen 13 Kämpfer stehen frei daneben. Freie Kämpfer stehen dort, wo sie gerade sind (neue — bei der Kaserne), und greifen Feinde in der Nähe von selbst an. Neue Kämpfer bildet nur die Kaserne aus: ohne sie und ohne Bestellungen liegen Schwerter und Bögen einfach herum.

**Verteidigung.** Jedes Militärgebäude hat eine unantastbare Mindestbesatzung: diese Kämpfer ziehen nie zum Angriff aus (die Burg behält 3, der Große Turm 2, der Wachturm 1). Wie in Settlers 4 hat ein besetzter Turm ein festes Tor (50 Punkte Haltbarkeit, repariert sich nach und nach): die Angreifer müssen es zuerst einschlagen, erst dann treten die Verteidiger zum Zweikampf heraus. Die Verteidiger sind stärker, weil sie auf eigenem Land mit voller Kraft kämpfen (siehe „Kampfkraft“), und die Bogenschützen der Besatzung, selbst unerreichbar, schießen 6–7 Felder weit auf alle Feinde auf Eurem oder herrenlosem Land (auf einen Feind, der auf seinem eigenen Land steht, nicht), aus dem Turm um 1 stärker, auf Feinde direkt an der Tür um 2. Verwundete heilen nur im Lazarett.

**Stufen.** Wie in Settlers 4 wird die Stufe eines Kämpfers in der Kaserne bestellt und ändert sich danach nicht mehr: Stufe 1 — nur die Waffe, Stufe 2 — plus 1 Gold, Stufe 3 — plus 2 Gold (das Gold fordert die Kaserne selbst an, solange Bestellungen über Stufe 1 vorliegen). Zuerst werden die höchsten Stufen ausgebildet, für die das Gold reicht, und Schwertkämpfer und Bogenschützen derselben Stufe kommen abwechselnd dran; ein üblicher Kniff, wie in S4, ist „∞“ auf Stufe 1 und Stufe 3: Stufe 3, wenn Gold da ist, sonst Stufe 1. Gesundheit und Schaden je Stufe wie in Settlers 4: Schwertkämpfer 100 / 150 / 210 Gesundheit und 10 / 14 / 20 pro Schlag, Bogenschütze 75 / 120 / 160 und 4 / 6 / 8 pro Schuss; die Stufe erkennt man am Helm: auf Stufe 1 ein Helm ohne Kamm, auf Stufe 2 mit kleinem rotem Kamm, auf Stufe 3 mit großem (in der alten Grafik `?art=classic` Winkel über dem Kopf), und die Zusammensetzung der Besatzung nach Art und Stufe steht in der Gebäudeinformation. Über einem ausgewählten Kämpfer erscheint ein Rahmen mit Gesundheitsbalken (grün → gelb → rot) und Stufenpunkten; verwundete Kämpfer im Kampf zeigen ihn auch ohne Auswahl. Der Kampf läuft wie in Settlers 4: es gibt keine Fehlschläge, jeder der beiden schlägt in seinem eigenen Takt zu (der Schwertkämpfer alle 0,9 s, der Bogenschütze alle 1,4 s), der Schaden wird mit der Kampfkraft an dem Ort multipliziert, an dem der Kämpfer steht; ein Zweikampf zweier Schwertkämpfer der Stufe 1 dauert etwa 9 Sekunden, und ein Schwertkämpfer der Stufe 3 besiegt einen der Stufe 1 und muss dabei höchstens fünf Schläge einstecken. Wenn jemand stirbt — Kämpfer, Siedler oder Esel —, steigt über ihm langsam ein helles Wölkchen in der Farbe seines Spielers auf und schwebt drei, vier Sekunden in der Luft, bevor es vergeht.

Um anzugreifen, klickt auf ein feindliches Militärgebäude: in der Information stehen die Zahl der Verteidiger und wie viele Eurer Kämpfer im Umkreis von 30 Feldern geschickt werden können — freie und in Formation stehende in der Nähe, dann überzählige aus Euren Militärgebäuden (und wer geht: Schwertkämpfer und Bogenschützen gemischt); mit „−“/„+“ wählt Ihr die Zahl und drückt „⚔ Angreifen“. Zuerst schlagen die Angreifer das Tor ein, dann kämpfen die Schwertkämpfer einzeln gegen die Verteidiger, und die Bogenschützen unterstützen sie mit Pfeilen; wenn keine Verteidiger mehr übrig sind, besetzt Euer Schwertkämpfer oder Bogenschütze das Gebäude — **nur einer zieht ein**, die übrigen bleiben draußen —, das Gebäude und sein Land gehen an Euch über, und fremde zivile Gebäude, die nun auf Eurem Land stehen, brennen ab (ihre Waren bleiben auf dem Boden und gehören Euch). Ihre Bewohner, nun ohne Heim auf fremdem Land, fliehen zu ihrem eigenen; finden sie es nicht in vier Etappen, sterben sie. Umstrittenes Land zwischen Militärgebäuden geht an das nächstgelegene.

**Direkte Steuerung.** Wie in Settlers 3/4 lassen sich Kämpfer direkt befehligen: freie stehen bei der Kaserne und bei den Türmen (überzählige holt „⬇ Abziehen“ oder „−“ aus einem Turm). Zieht einen Rahmen um Eure Kämpfer (linke Maustaste) oder klickt einen einzelnen an; wie in Settlers 4 fügt Strg+Klick zur Auswahl hinzu, Umschalt+Klick nimmt alle Kämpfer dieser Art in der Nähe, Alt+Klick — im ganzen Sektor, ein Doppelklick — auf dem Bildschirm, und die Rücktaste behält in der Auswahl nur die Verwundeten. Ausgewählte sind mit grünen Ringen markiert, und in der linken Leiste erscheint das Fenster „Truppe“: wie viele Kämpfer jeder Art und Stufe, ihre Gesundheit und die Knöpfe „Halten“, „In die Besatzung“ (jeder ins nächste eigene Militärgebäude mit freiem Platz seiner Art), „Auswahl aufheben“. Ein Rechtsklick erteilt einen Befehl: auf den Boden — sich dort in Formation aufstellen (jeder geht auf seinem eigenen Weg zu seinem Platz, wie in S4), auf ein feindliches Militärgebäude — angreifen, auf ein eigenes — einziehen (der Turm behält sie). Kämpfer im Feld stehen, wo man sie hingestellt hat, und greifen Feinde in der Nähe von selbst an; wie in Settlers 4 kann ein Turm, dem Kämpfer fehlen (leer oder nach „Auffüllen“), auch sie rufen; Bogenschützen schießen aus dem Feld, Bogenschützen in Türmen auf Feinde an den Mauern.

**Spezialisten gehorchen der Maus ebenso.** Geologen, Pioniere und Diebe lassen sich mit einem Rahmen oder per Klick auswählen — zusammen mit Kämpfern oder getrennt. Ein Rechtsklick gibt jedem den passenden Befehl: der Geologe erkundet auf einem Berg (auch jenseits der Grenze) das ganze Gebirge, der Pionier besetzt herrenloses Land, der Dieb zieht zu einem erkundeten feindlichen Lagerhaus, um zu stehlen (die Beute trägt er in ein eigenes Lagerhaus, das sie annimmt, und gibt es keines, legt er sie bei sich auf den Boden); an jedem anderen Ort geht der Spezialist einfach hin und wartet. Neben dem Cursor zeigt ein Hinweis, was ein Rechtsklick bewirkt. Im Fenster „Truppe“ werden Spezialisten nach Art gezählt, „✋ Halten“ hält sie an, „↩ Entlassen“ macht sie wieder zu Trägern (nur auf eigenem Land).

**Spezialisten auf fremdem Land sind in Gefahr, wie in Settlers 4.** Ein Geologe, Pionier oder Dieb, der feindliches Land betritt, lockt dessen Schwertkämpfer an: der nächste Turm schickt einen Kämpfer (wenn er welche über die unantastbare Mindestbesatzung hinaus hat), freie Kämpfer und Truppen im Feld in der Nähe greifen von selbst an, Bogenschützen schießen. Spezialisten wehren sich nicht (Gesundheit wie in Settlers 4: Geologe und Pionier 25, Dieb 20 — der Schwertkämpfer 100). Der Dieb ist verkleidet — er wird nicht bemerkt, bis ein feindlicher Kämpfer in seiner Nähe ist. Auch ein **beladener Esel** auf fremdem Land ist Beute: wird er getroffen, stirbt er nicht, sondern wirft beide Packen auf den Boden (die Träger des Landbesitzers sammeln sie auf) und geht nach Hause. Genauso empfangen Eure Schwertkämpfer fremde Spezialisten und Esel auf Eurem Land.

**Truppführer.** Die Waffenschmiede schmiedet außer Schwertern und Bögen auch Rüstungen (ihren Anteil stellt Ihr im Menü „Armee“ oder im Fenster der Waffenschmiede ein). Auf Bestellung macht die Kaserne aus Rüstung, Schwert und 3 Gold einen Truppführer — einen Kämpfer mit vergoldetem Helm mit hohem rotem Kamm, goldenem Kürass, rundem goldenem Schild und Umhang. Wie in Settlers 4 hat er 215 Gesundheit, 21 Schaden pro Schlag und eine Rüstung, die von jedem Schlag gegen ihn 2 abzieht (aber nicht unter 1) — Pfeile können ihm also kaum etwas anhaben; Kämpfer in seiner Nähe (innerhalb von 6 Feldern) schlagen 10 % stärker zu. Wie in Settlers 4 erobert der Truppführer keine Gebäude und zieht in keinen Turm ein — er ist immer im Feld. Eine Truppe, die mit einem einzigen Befehl um den Truppführer aufgestellt wurde, hält die Formation: schickt nur den Truppführer los — die Truppe folgt ihm.

**Kampfkraft.** Wie in Settlers 4 kämpfen die Kämpfer auf eigenem Land immer mit voller Kraft, auf fremdem dagegen mit der Kampfkraft, die in der oberen Zeile angezeigt wird. Sie wächst mit dem Wert der Siedlung: Bretter, Baumstämme und Stein in allen fertigen Gebäuden, Gold doppelt und die Baustoffe von Zierden dreifach; das Wachstum verlangsamt sich allmählich (bis 150 %). Zu Beginn sind es bei zwei Spielern 50 %, einen entwickelten Nachbarn mit einer armen Siedlung anzugreifen ist also schwer. Die Verteidigung auf eigenem Land beträgt 100 %, und wenn die Kampfkraft 100 % übersteigt, wächst auch sie, halb so schnell.

**Der Computergegner.** Er spielt nach denselben Regeln wie Ihr: baut dieselben Gebäude aus denselben Baustoffen, schickt Geologen, bestellt in der Kaserne Schwertkämpfer und Bogenschützen (wie die KI von Settlers 4: auf „Leicht“ nur Stufe 1, sonst alle Stufen — die höchste, wenn das Gold reicht), fördert Gold und dehnt sich mit den größten Türmen aus, die er bauen und besetzen kann — zuerst zu den Rohstoffen, dann zu Euch. Türme an seiner Grenze und bei Euren Gebäuden füllt er auf, die übrigen Kämpfer hält er frei an einem Sammelpunkt hinter seinem vordersten Turm — von dort ziehen sie zum Angriff und zur Hilfe. Die ersten 25 Minuten greift er nicht an; danach greift er an, wenn die Stärke seiner freien Kämpfer (unter Berücksichtigung der Stufen und seiner Kampfkraft auf fremdem Land) deutlich größer ist als die der Verteidiger des Ziels zusammen mit Euren Kämpfern, die er in dessen Nähe sieht (etwa 1,2 zu 1; die Stärke eines Kämpfers rechnet er als Gesundheit × Schaden pro Sekunde — das, womit man sich im Zweikampf misst). Er schickt so viele, wie mit Reserve nötig sind, die übrigen bewachen weiter seine Türme; gegen Euer letztes ihm bekanntes Militärgebäude — alle. Er wählt Ziele, die zu Eurem Startplatz führen, und hat er dort ein Militärgebäude gefunden, zieht er große Türme und Burgen davor zusammen, um eine geballte Faust zu bilden; nach einer erfolgreichen Eroberung schlägt er schneller wieder zu, bevor Ihr Euch neu formiert habt. Eure Kämpfer, die ins Feld auf sein Land ziehen, empfängt er mit einer Feldtruppe, wenn er mindestens ebenso viele aufbieten kann, sonst wehrt er sich hinter seinen Mauern. Ist ein Teil seines Landes von den Lagerhäusern abgeschnitten (zum Beispiel ein eroberter Turm in der Ferne), baut er dort einen Marktplatz, einen weiteren zu Hause und eine Eselzucht und bringt mit Eseln dorthin, was fehlt, und zurück, was dort erzeugt wird. Aus überschüssigem Stein und Brettern baut er Zierden, und Pioniere und Diebe setzt er genauso ein wie Ihr. Wie in Settlers 4 besteht der Schwierigkeitsgrad vor allem aus Vergünstigungen für den Computer: bei jedem Computerspieler geht das Erz in den Minen nie aus, auf „Mittel“ und „Schwer“ bekommen die Minen zusätzliche Versuche (und arbeiten manchmal ohne Nahrung), und die Baustoffe seiner Gebäude zählen doppelt für seine Kampfkraft; zu Beginn hat er einen Zuschlag aus dem S4-Szenario — Bretter, Stein, 5 Pioniere (auf „Mittel“ und „Schwer“ doppelt so viel und noch 5 Schwertkämpfer). Er greift, wie die KI von S4, an, wenn er mindestens 15 Kämpfer hat und der Zufall es will (die Chance steigt mit jedem Mal), und einen ihm abgenommenen Turm versucht er sofort mit einem Gegenangriff zurückzuholen. Erz sieht er nur dort, wo seine Geologen waren, und Eure Gebäude nur dort, wo sich sein Nebel des Krieges gelichtet hat: solange er Euch nicht gefunden hat, treibt er Türme vor und stellt Aussichtstürme in Richtung der unerkundeten Startplätze; bemerkt er Euer Militärgebäude bei Eurem Startplatz, zieht er Türme heran, um es zu belagern; die Zahl der Verteidiger kennt er nur, solange das Gebäude im Sichtfeld seiner Gebäude liegt. Für eine Mine, der Erz fehlt, schickt er Geologen und treibt Türme zu den Bergen vor.

**Sieg und Niederlage.** Ausgeschieden ist, wer kein einziges besetztes Militärgebäude (Wachturm, Großer Turm, Burg) und keinen einzigen Kämpfer mehr hat — solange noch ein Schwertkämpfer oder Bogenschütze lebt (im Feld, bei einem verlorenen Turm, im Lazarett), geht das Spiel weiter, und man kann wieder einen Turm bauen und ihn hineinsetzen. Hat der Computer den letzten Turm genommen, macht er die übrigen Kämpfer nieder. Beim Ausgeschiedenen brennen die Gebäude ab (die Waren bleiben liegen), das Land wird herrenlos, und die Siedler lassen die Arbeit liegen, irren noch eine Weile umher und sterben. Ihr habt gewonnen, wenn alle Gegner ausgeschieden sind, und verloren, wenn Ihr selbst ausgeschieden seid. Am Ende erscheint die Bilanz der Partie mit den Knöpfen „Neues Spiel“ (der Einrichtungsbildschirm im Hauptmenü) und „Weiter zusehen“.

Bauen dürft Ihr nur auf eigenem Land: es ist hervorgehoben, die Grenze ist mit Pfählen mit Würfeln in der Spielerfarbe markiert (wie in Settlers 4), und dahinter ist das Land abgedunkelt. **Das Land hält wie in Settlers 4:** ein besetzter Turm übt auf die Felder um sich „Einfluss“ aus (je näher, desto mehr), und ein Feld geht nur dann an einen anderen Spieler über, wenn es herrenlos ist oder sein Besitzer dort keinen Einfluss mehr hat. Deshalb verschwindet das Land nicht, wenn ein Turm abgerissen wird, abbrennt oder leer wird — es bleibt Euer, bis ein fremder Turm es abdeckt. Ein neuer Turm an einer fremden Grenze nimmt kein Land, das ein fremder Turm noch hält (die Grenze verläuft zwischen ihnen), und ein eroberter Turm nimmt nur, was der frühere Besitzer mit nichts anderem mehr hält; Eure Gebäude auf Land, das an den Feind übergeht, brennen ab. Sammler, Förster und Bauern arbeiten ebenfalls nur innerhalb ihrer Grenzen, für neue Wälder, Steinbrüche und Wasser müsst Ihr Euch also mit Türmen ausdehnen. Äcker sind begehbar, aber bebauen lassen sie sich nicht.

Das Land ist nicht flach: das Gras ist leicht hügelig, Berge erheben sich über die Ebenen, und das Wasser liegt am tiefsten. Von den Bergen fließen Flüsse zum Meer (auf großen Karten ziehen sich die Berge in Ketten hin), und an den Flüssen gibt es alle paar Felder Furten — seichte Stellen, an denen man hinübergehen kann. Die Übergänge zwischen Wasser, Sand, Gras und Bergen sind weich.

Fern vom Wasser gibt es **Wüsten**: dort kann man gehen und bauen, aber nichts wächst — weder Bäume noch Äcker. In Senken am Wasser gibt es **Sümpfe**: wie in Settlers 4 sind sie unpassierbar, man kann auf ihnen weder bauen noch pflanzen. Das Land ist dabei nie zerschnitten: durch Sümpfe führen trockene Pfade, durch geschlossenen Wald Schneisen. Rund um die Burg gibt es weder Wüsten noch Sümpfe.

**Nebel des Krieges.** Zuerst seht Ihr nur die Umgebung des Startturms, der Rest der Karte ist schwarz. Wie in Settlers 4 ist Euer ganzes (und das verbündete) Land vollständig sichtbar, dazu ein Streifen von 2 Feldern jenseits der Grenze; besetzte Militärgebäude sehen weiter (Wachturm 14 Felder, Großer Turm 15, Burg und Aussichtsturm 17), Siedler 7 Felder um sich herum, der Dieb 10. Einmal Gesehenes bleibt auf der Karte, aber wenn dort gerade keiner der Euren ist, ist die Gegend abgedunkelt: fremde Siedler sind dort nicht zu sehen, und bei feindlichen Gebäuden ist die Besatzung nicht zu sehen. Die Minikarte zeigt dasselbe. Der Computergegner unterliegt denselben Regeln: er weiß nur, was er selbst erkundet hat.

Wie in Settlers 4 sind, solange ein Gebäude zum Bauen ausgewählt ist, auf der Karte alle Stellen mit Punkten markiert, an die es passt: **grüne** — eben, **gelbe** — der Bauplatz ist geneigt, zuerst ebnet ihn ein Planierer. Jede Baustelle räumt zuerst ein **Planierer** mit Schaufel (zu Beginn sind es zwei; mehr auf Bestellung im Menü „Siedler“); sobald ein Planierer zur Baustelle unterwegs ist, beginnen die Träger, Baustoffe zu bringen, und erst danach kommen die Bauarbeiter. Wie in Settlers 4 liegen auf einer Baustelle höchstens 8 Stück jedes Baustoffs (die unterwegs mitgezählt) — deshalb dauern große Gebäude länger. „⬆ Vorrang“ einer Baustelle (höchstens 10 gleichzeitig) ist streng: solange die bevorzugte Baustelle einen Baustoff braucht, bekommen die übrigen Baustellen auf diesem Land ihn nicht; ist sie fertig, wird der Vorrang von selbst aufgehoben. Wie im Original arbeiten auf einer Baustelle mehrere Planierer gleichzeitig (je mehr zu graben ist, desto mehr, bis zu 8) und mehrere Bauarbeiter (bei einer Hütte 3, bei einem großen Wohnhaus 5); ihre Arbeit addiert sich, und wie viele es gerade sind und wie viele gebraucht werden, steht in der Information zur Baustelle. Einen zu steilen Hang zeigt das „Geisterbild“ des Gebäudes rot. Minen brauchen keinen Planierer. Die Flagge auf dem Dach geht hoch, wenn das Gebäude bezogen ist: in eine Werkstatt ist ein Arbeiter gekommen, in einen Turm Soldaten.

Auf Bergen kann man gehen, aber bauen lassen sich dort nur Minen. Unpassierbar sind nur die mit Felsbrocken übersäten Felsgipfel.

Auf der Karte streifen wilde Tiere umher: Hirsche an Waldrändern, Esel und Hühner auf Wiesen, Enten am Wasser. Sie leben für sich, stören niemanden und sind nur dort zu sehen, wo Ihr Sicht habt. Auf Hirsche macht der Jäger Jagd.

Bäume wachsen in vier Stufen (fällen lassen sich nur ausgewachsene), Äcker ebenfalls in vier (ernten lassen sich nur reife). Setzlinge versperren nie Durchgänge. Selbstaussaat gibt es nicht, wie in Settlers 4: neue Bäume pflanzen nur Förster.

### Ton

Der Ton schaltet sich nach dem ersten Klick oder Tastendruck ein (so verlangen es die Browser). Zu hören ist, was auf dem Bildschirm zu sehen ist: das Klopfen von Äxten und Hämmern, Spitzhacken, die Säge, Wasserplätschern, fallende Bäume, Schwertgeklirr und Bogensehnen, das Signal einer fertigen Baustelle. Je weiter von der Bildschirmmitte, desto leiser, und links und rechts kommt der Ton aus dem jeweiligen Lautsprecher. Im Hintergrund spielt ruhige Musik, und Vögel singen; das Intro eröffnet ein eigenes Thema — eine Hornmelodie über Akkorden und Trommel. Lautstärke, Stummschaltung und Musik merkt sich der Browser.

## Technologien

- **TypeScript + Vite** — Build und Dev-Server.
- **PixiJS 8** — Rendering mit WebGL.
- **Vitest** — Tests der Simulation.

- **Blender** (für das Spiel nicht nötig) — 3D-Modelle und Sprite-Rendering.

Die Grafik besteht standardmäßig aus in Blender vorgerenderten Bildern aus `public/art/3d` (Modelle und Render-Skripte liegen in `art/`); beim Start werden sie zu einem Texturatlas zusammengesetzt. Mit `?art=classic` kommen stattdessen die alten Sprites zum Einsatz, die per Code auf Canvas 2D gezeichnet werden (sie dienen auch als Ersatz für alles, wofür es kein 3D-Bild gibt). Alle Klänge werden mit WebAudio synthetisiert, es gibt keine Sounddateien.

## Struktur

```
src/sim/      Simulation ohne Browserabhängigkeiten: Karte, A*, Siedler, Gebäude, Logistik
src/render/   isometrisches Rendering mit PixiJS, Sprite-Erzeugung, Animationen und Effekte, Kamera
src/audio/    Klangsynthese, Musik, Lautstärke und Positionierung
src/ui/       HTML-Oberfläche, Eingabe, gemeinsamer Zustand
src/i18n/     Oberflächentexte: Russisch (Hauptsprache), Englisch, Deutsch
src/dev/      Demokarte ?demo für die Entwicklung
src/tutorial/ das Tutorial: Missionen als Daten, Bedingungen, Anker, der Schrittautomat, die Zielleiste
tests/        Tests (Simulation, Animation, Ton, Demokarte)
tools/        Konsolenprüfungen: Wirtschaft, Geschwindigkeit, Computer gegen Computer
art/          Blender-Modelle, Bodentexturen und Render-Skripte der 3D-Grafik
public/art/3d/ fertige 3D-Sprites
docs/         Plan, Abgleich mit Settlers 4, Grafikstil, Entwicklerhandbuch
```

Die Simulation läuft in festen Ticks (10 pro Sekunde) und ist durch den Seed deterministisch; das Rendering liest nur ihren Zustand und glättet die Bewegung zwischen den Ticks. Wie man entwickelt (Start, Tests, Konsolenprüfungen, Demokarte, Adressparameter, Debugging, Grafik in Blender, Veröffentlichung), steht in [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) (auf Russisch). Mehr über den Aufbau des Codes steht in [CLAUDE.md](CLAUDE.md) und in der [ursprünglichen Spezifikation des Prototyps](docs/superpowers/specs/2026-10-06-settlers-prototype-design.md) (historisch, beschreibt die allererste Version).

## Befehle

```bash
npm run dev         # Dev-Server
npm test            # Tests
npm run typecheck   # Typprüfung
npm run build       # Production-Build nach dist/
npm run sim:probe   # Wirtschaftsprüfung: eine Spielstunde auf mehreren Karten
npm run sim:bench   # Geschwindigkeitsmessung der Simulation: Karte 256×256, 1000 Siedler
npm run sim:ai      # Computer gegen Computer (oder gegen einen passiven Spieler: --passive=1), eine Spielstunde lang
npm run art:render  # 3D-Sprites nach public/art/3d neu rendern (braucht Blender; auch einzeln: -- sawmill trees piles)
npm run art:quantize # nach dem Rendern: 3D-Sprites auf 256 Farben reduzieren (braucht Pillow)
npm run art:settlers # Siedlerfiguren neu rendern (etwa 15 Minuten) und reduzieren
npm run art:ground  # Bodentexturen aller Arten, Äcker und Pfade in public/art/3d neu erzeugen (braucht Blender)
npm run art:animals # Tierbögen in public/art/3d neu rendern (braucht Blender; auch: -- deer duck)
```

## Wie es weitergeht

Wirtschaft, eine Armee mit direkter Steuerung, Spezialisten, Esel und Märkte, Computergegner und 3D-Grafik gibt es bereits. Als Nächstes kommen weitere Völker (Wikinger, dann Maya und Trojaner) mit eigenen Gebäuden, Waren und besonderen Kämpfern, danach Kampagnen, ein wirtschaftlicher Sieg und das Netzwerkspiel (mit ihm der Saboteur). Magie (und mit ihr Wein), das Dunkle Volk, einen Karteneditor, Jahreszeiten und Wolkenschatten gibt es im Plan nicht; Schiffe, Häfen und Kriegsmaschinen vorerst auch nicht. Der ausführliche Plan steht in [docs/ROADMAP.md](docs/ROADMAP.md) (auf Russisch), der Abgleich mit Settlers 3/4 (was wie im Original ist, was anders und warum) in [docs/S4-PARITY.md](docs/S4-PARITY.md) (auf Russisch).
